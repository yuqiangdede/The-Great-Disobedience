# 深度剧情体系与分卷因果规划指南

单一大纲文件在短篇中有效，但在长篇中无法承载复杂的叙事因果与多阵营博弈。
深度剧情体系将剧情分为三层：**全书总纲 -> 分卷因果大纲 -> 单章写作任务卡**。

---

## 一、分卷大纲核心法则：因果三问

任何一卷的剧情大纲，严禁只写“发生了什么结果”（例如“要塞被攻破”）。
必须在 `03-剧情/第X卷-[卷名].md` 中完整回答以下三个问题：

### 1. 本卷发生了什么核心事件？
- 外部世界与格局的重大质变（如：停火协议破裂、缓冲要塞遭到围攻覆灭、主角团被迫流亡）。
- 阵营势力的战略意图与利益驱动（为什么各方势力必须在此时打破均势？）。

### 2. 人物为什么做出这种选择？
- 基于人物的性格缺陷、核心信念与**当时所掌握的局限信息**做出的必然决策。
- 绝非作者为了推动剧情强行安排的降智或剧情杀。
- 主角团在覆灭/危机前曾有过哪些破局尝试？为什么这些尝试基于现实规律必然失败？

### 3. 这些选择造成了什么不可逆转的后果？
- 为下一卷埋下不可挽回的代价与现实约束（如：失去了根据地与重武器、某位核心队员残疾或牺牲、与原宗主阵营彻底决裂）。
- 人物心理认知发生不可逆蜕变（从依附旧体制到彻底幻灭自立）。

## 三、单章任务卡 (`05-写作计划/章节任务卡/第XXX章-任务卡.md`)

在动笔写单章前，AI 或作者生成任务卡，作为单章写作的直接指令依据。

```markdown
# 第[XXX]章 写作任务卡

## 1. 基本信息
- **章节标题**：
- **所属分卷**：
- **预计字数**：3000 - 5000 字
- **场景地点**：（必须符合地理地图规范）

## 2. 剧情要素
- **出场人物**：（本章实际出场的角色）
- **前置因果（承接上章）**：（上章结尾留下何种物理/心理状态）
- **核心冲突与主要事件**：（本章内必须爆发的冲突）
- **意外转折 / 打破预期点**：（至少1个非套路的意外发现）
- **结尾悬念钩子**：（具体悬念类型与收尾事件）

## 3. 写作约束与资源调用
- **登场人物实时状态约束**：（引用自 `07-创作记忆/人物实时状态.md`，如负伤、体力透支、装备短缺）
- **人物已知情报边界**：（明确本章角色绝不能知道的情报，严防剧透）
- **需调用的世界观/装备专题**：（如需读取 `01-世界观/军事装备与技术.md` 第2节）
```
