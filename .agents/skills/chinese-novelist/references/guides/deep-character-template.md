# 深度人物独立档案模板与层级管理规范

> 本规范与模板是长篇/复杂小说人物的**可选深度小传参考（权威事实来自项目已确认的人物档案）**。
> 严禁将所有角色混写在一个单文件内，必须按层级独立建档。
> 严禁只堆砌“坚毅、冷静、重情义”等抽象形容词，必须定义其**行为逻辑**与**禁止偏离清单**。
>
> 💡 **小传定位与使用原则**：
> 1. **冰山原则**：**小传没必要所有的情节都在正文中提及，只是为性格和人物建立一个基础而已**。切忌在正文中全盘倒灌小传背景经历或写成流水账，重点是为人物性格、行为习惯和心理动机打牢地基。
> 2. **合规性校验输入**：**后续合规性校验（合规性教研 / Quality Gate）时将小传作为权威基准输入**，严格对照核验正文中的角色反应、抉择动机与负面禁令，确保人设永不崩塌。

---

## 一、三级分类目录结构规范（主角 / 配角 / 辅助角色+章节）

为方便后续章节写作时快速检索、避免人设漂移与遗忘，所有人物小传在 `02-人物/` 下严格按照三级分类分目录管理：

```
02-人物/
├── 人物总表.md                          # 全局人物出场矩阵（主角、配角、辅助角色分类索引）
├── 人物关系与冲突.md                     # 核心团队内部关系与外部利益博弈矩阵
├── 主角/                                # 灵魂人物独立主档（全员立传）
│   └── [角色名].md                      # 如：角色甲.md
├── 配角/                                # 核心副手、主要队友、重要反派、深度羁绊角色（全员立传）
│   ├── [角色名].md                      # 如：角色乙.md, 角色丙.md, 角色丁.md, 角色戊.md, 角色己.md
│   └── ...
└── 辅助角色/                            # 次要角色、阶段功能NPC、周期性复现角色（以登场章节前缀命名）
    ├── 第001章-[角色名].md               # 如：第001章-边民老猎户.md, 第001章-王铁柱.md
    ├── 第002章-[角色名].md               # 如：第002章-友邻阵营联络哨长.md
    └── ...
```

### 核心建档铁律：主角配角全员立传，多次登场必建小传
> ⚠️ **核心法则**：**主角和配角都要有人物小传，理论上只要多次出现的人物都要设立小传！**
> - **必须建档（设立独立小传）**：
>   1. **主角与核心配角**：全员必立独立小传；
>   2. **多次出现/后续复现角色**：理论上只要在书中多次出现、或在后续章节/分卷有复现可能或计划的角色；
>   3. **关键推动者**：在本章承担关键剧情推进、提供核心道具/情报、引发危机或转折的角色；
>   4. **深度交互角色**：拥有具体姓名、战术/职业特长，与主角或核心配角产生深度言行交互的角色；
>   5. **常驻功能角色**：驻地军医、老工匠、常驻哨长、敌方侦察小队长等常驻/功能性辅助角色。
> - **免建特例（纯一次性龙套）**：
>   - 仅限纯背景过客、无名背景板，且全书绝无二次登场可能的路人（如“无名小二端上一碗水即走”、“城门守卫查验路引挥手放行”等）。

## 二、模板一：主角与核心配角 10 维深度独立档案模板

适用于：`02-人物/主角/[角色名].md` 与 `02-人物/配角/[角色名].md`。

```markdown
# 人物档案：[角色姓名/代号]

## 1. 基础信息
- **姓名/曾用名/代号**：
- **首次登场**：第XX卷 / 第XX章
- **角色定位**：主角 / 核心配角（主要队友 / 关键反派）
- **生理年龄/外观年龄**：
- **出身背景**：（故乡、阶层、家庭印记）
- **所属阵营与历史编制**：（当前职务、过往从属、军衔或身份）
- **外貌特征与标志性细节**：（面部特征、陈旧伤痕、日常着装习惯、辨识度极高的小动作）
- **人物视觉插画/立绘（可选）**：[只在当前作品已有立绘文件时填入其实际相对路径，不预留失效图片链接]

## 2. 人生经历与关键转折
- **早期塑造期**：（童年/少年经历，决定了其最底层的安全感来源）
- **高光/巅峰期**：（曾经获得的荣誉、地位或力量峰值）
- **重大创伤事件（信仰崩塌点）**：（导致其人生发生剧变的转折点，如重伤、背叛、理想破灭）
- **加入当前势力的因果**：（为何流落至此/为何选择现在的道路，必须有充分的现实或心理因果）

## 3. 战斗能力与特长
- **能力评级/体系位阶**：（如 A级老兵、五阶术师等）
- **战术特长与擅长领域**：（近身格斗、战术侦察、重武器操纵、心理诱导等）
- **生理缺陷与战斗弱点**：（旧伤后遗症、体能衰退、盲区、反应迟钝部位）
- **战术习惯**：（先手动作、习惯性掩护方向、遇伏后的本能反应）

## 4. 特异禀赋 / 特殊能力（如有）
- **能力名称与感知/表现效果**：（用感官可感知的文字描述，而非概念化名词）
- **启动前置条件**：（特定的生理状态、心理阈值、辅助器械或环境要求）
- **生理与心理代价**：（使用后伴随的剧痛、器官衰竭、感知麻木、认知错乱或寿命消耗）
- **失效条件与克制机制**：（在何种环境或敌方手段下会彻底失效）

## 5. 人格与行为底层逻辑（约束 AI 跑偏的核心）
- **外显性格**：（外人眼里看到的性格标签）
- **核心行为逻辑（必须详写情境决策）**：
  - *何时愿意牺牲个人利益*：（明确触发舍己为人的具体底线，如“为保护无武装平民或朝夕相处的队员，但绝不为政客的高调口号牺牲”）
  - *何时会坚决违抗命令*：（什么指令会突破其心理红线，如“要求屠杀已投降的敌军老兵或掩盖真相”）
  - *什么极端情境会使其失去冷静*：（精准的创伤触发点，如“看到当年导致小队覆灭的同款毒气罐”）
  - *始终无法割舍的旧观念/制度印记*：（旧阵营或过往生涯刻在骨子里的习惯，哪怕已被旧阵营抛弃仍下意识遵守）
- **致命心理缺陷与最大恐惧**：（其性格中的阿喀琉斯之踵，如恐惧被遗忘、内疚自责、无法信任权威）

## 6. 核心信念与终极动机
- **他究竟相信什么？**：（其世界观的基石，如“秩序必须有人维护，即便维护者注定被碾碎”）
- **在残酷世界依然坚持行动的根本动力**：（不是宏大的救世口号，而是具体的执念，如“让最后一个队友活着退役”）

## 7. 阵营归属与人际关系网络
- **与核心队友关系矩阵**：
  - 对队友A：信任程度、沟通模式、潜在分歧点
  - 对队友B：...
- **与旧势力的恩怨纠葛**：（复杂情感，爱恨交织，不可简单写成单一仇恨）
- **对主要敌对势力的认知**：（知己知彼的战术评价，而非脸谱化敌视）

## 8. 分卷人物弧线（认知与立场的演变）
- **第一卷**：初始立场，对现状的妥协与微弱希望；
- **第二卷**：核心事件冲击，信仰二次动摇；
- **第三卷**：被迫出走/反叛，探索新出路；
- **后续卷**：立足、反抗与重构秩序。

## 9. 终局命运与边界
- **作者预设宿命**：（牺牲、隐退、成为新秩序的奠基石等）
- **不可突破的底线**：（无论剧情多绝望，该角色绝不会做的事）

## 10. 禁止偏离清单（Negative Constraints，硬性红线）
- ❌ **绝对禁止**：在未经剧情长线铺垫的情况下突然掌握高超政治斡旋才能或高瞻远瞩的战略视野。
- ❌ **绝对禁止**：忽视旧伤设定的超人级机动（如右腿液压受损时还能飞身回旋踢）。
- ❌ **绝对禁止**：在危急关头毫无逻辑地发表冗长煽情演讲。
- ❌ **绝对禁止**：突兀使用现代流行语、戏谑网络梗。
- ❌ **绝对禁止**：与未建立信任的新角色瞬间掏心掏肺。
```

## 三、模板二：辅助角色精悍小传模板（次要/功能/周期复现角色）

适用于：`02-人物/辅助角色/第{XX}章-[角色名].md`。
以**首次登场章节**命名，篇幅精悍（300-600字），重点突出**剧情功能**、**行为底线**与**后续复现预设**，既保证不漏设定，又极大节省写作与维护成本。

```markdown
# 辅助角色档案：[角色姓名/代号]

## 1. 基础信息
- **首次登场章节**：第XX章
- **角色定位**：辅助角色（常驻辅助 / 阶段功能角色 / 周期性复现角色）
- **所属阵营与身份**：（如：主角所属阵营大峡谷巡防小队长、友邻阵营避难所药剂师等）
- **外貌特征与标志细节**：（1-2个辨识度极高的细节，如断指、熏黑的皮护肩、浓重鼻音）

## 2. 剧情功能与情节使命
- **本章核心作用**：（在本章中起到何种剧情推进作用？如引出灭口真相、提供关键军规引信、促成情报拼图）
- **与主角/核心队伍关系**：（利益交换、过往恩情、戒备防范、旧相识等）
- **后续出场与伏笔预设**：（后续是否再次出场？预计在何卷/何章复现？承担何种伏线？）

## 3. 性格与行为底线
- **显性性格**：（如：市井圆滑、谨小慎微、嗜烟如命但极讲信义）
- **核心行为逻辑与底线**：
  - *何时愿意提供协助*：（如：给足物资报酬或不触怒官方时）
  - *何种情况会立刻抽身/拒绝*：（如：一旦涉及合众军正规部队报复，绝不蹚浑水）
- **说话风格与台词习惯**：（口头禅、生活化黑话、语气特征，拒绝播音腔）

## 4. 关键特长或战斗能力（如有）
- **特长/技能**：（如：擅长高频引信检修、熟悉边境三号密道）
- **生理短板与局限**：（如：无外骨骼加持、年迈反应迟钝）

## 5. 禁止偏离清单（Negative Constraints）
- ❌ **绝对禁止**：突然具备超越其辅助身份的战略大局观或超凡战力。
- ❌ **绝对禁止**：无铺垫背叛已建立的市井利益底线。
- ❌ **绝对禁止**：在危急交火场景下发表脱离身份的哲学感慨。
```
