# 审稿与设定核查规范 (`08-审稿/`)

长篇小说创作最怕的是“边写边忘”、“时间线前后打架”、“主角人设突然崩塌”以及“AI 现场生造设定”。
正式正文保存前应核对与其相关的事实、角色、时间、场景及工程要求；确认的实质错误与未通过的项目工程门禁仍须处理，不能用机器 PASS 代替语义审稿。

---

## 一、四维硬拦截质检维度

### 1. 时间轴与多主角年龄/主线事件合规性核验（Timeline & Chronology Gate）
- **世界主线时间节点锚定**：
  - 章节必须明确其在世界纪元中的时间坐标（年份、月份、日期、季节节令）。
  - 核验正文出现的年份与环境，严禁出现时空倒流、反季节天候（如严冬出现蛙鸣蝉叫、骄阳似火等严重冲突）。
- **多主角实岁与生命阶段核对**：
  $$\text{主角当前实岁} = \text{当前世界年份} - \text{主角出生年份}$$
  - 正文中引用的自报年龄（如“年方二十”、“时年三十有四”）必须与理论实岁严格一致，误差 $\ge 1$ 岁直接判定阻断（`BLOCKED`）。
  - **生命周期合法性**：主角未出生前（$\text{世界年} < \text{出生年}$）严禁作为实体登场；已阵亡角色在阵亡年份后严禁现场行动（回忆除外）；规划在后续分卷登场的角色严禁在前卷提前以老队员身份登场互动。
  - **人生阶段约束**：角色的军衔、职务、战力必须符合其在当前世界年份所处的人生阶段（如少年苦工阶段严禁作为资深军官指挥战斗）。
- **世界主线事件时刻表核查（防因果颠倒与早产剧透）**：
  - 核验 `worldEventsTimeline`，严禁将未来尚未发生的大事件（如后续分卷才爆发的全面热战或城邦陷落）在当前章节写成“已然发生、早已覆灭”的既成事实。
- **时空位移与历时合理性**：
  - 跨地理区域移动（如边陲到京城）必须符合地理尺度与交通工具的物理耗时（马匹、舟车、摩托、步行），严禁出现无铺垫的“一日千里/瞬移抵达”。

### 2. 情节合理性与状态继承（Plot Plausibility & Injury Continuity）
- **因果与伏笔前置**：
  解谜道具、关键援军或特殊技能必须在前文（至少前 1~3 章）有明确交代或合理铺垫，严防“机械降神”与临时顿悟。
- **生理伤病与物资继承**：
  严格核对 `07-创作记忆/人物实时状态.md`。上一章的骨折、中毒、内伤或物资告罄必须在正文行动中形成具体阻碍，严禁“满血复活”或无代价超人发挥。
- **行为代价与守恒**：
  重大抉择必须产生不可逆后果，敌对阵营与配角反应需符合各自利益诉求，严禁降智配合。

### 3. 人物小传合规性教研与负面禁令核验（Persona & Bios Compliance Check）
- **小传作为合规性校验输入（Ground Truth Input）**：
  主角、配角及多次出现角色的独立小传是本维度合规性校验（合规性教研）的核心输入。审稿时必须将登场角色的小传作为输入比对，核查其在本章的决断、情绪反应、言行风格是否符合小传设定的性格底色与行为逻辑。
- **冰山原则审校尺度**：
  **小传没必要所有的情节都在正文中提及，只是为性格和人物建立一个基础而已**。审稿重点在于言行一致性与动机合规，切勿苛求正文全盘交代小传中的生平往事，严禁因未把小传所有细节写进正文而判定不合规。
- **底层行为逻辑**：
  在利益诱惑与生死冲突面前，主角决策必须符合人物主档定义的“底层逻辑”与“核心驱动力”。
- **禁止偏离清单（硬性红线）**：
  核对 `02-人物/` 下登场角色（主角、配角、多次出现角色）小传中的【禁止偏离清单】。凡触碰任一条款且无合理剧情铺垫的，直接判定为人设崩塌（OOC 阻断，必须重修）。
- **已知情报边界（严防全知剧透）**：
  核对 `人物实时状态.md` 中的【已知情报边界】与【未知警戒线】。角色言行与心理活动严格受限于已知信息，严禁以全知视角泄漏未解开的伏笔。

### 4. 文风与去 AI 味（Humanizer-zh × 说人话 标准）
- 是否调用或严格执行了 `op7418/Humanizer-zh` 与 `MrGeDiao/shuorenhua` 双重润色？
- **双源文风契合度（正文越多越契合本书已沉淀语感）**：核对是否贴合 `03-文风基准.md` 的当前双源动态权重指示牌。随着正文章节累积，是否深度对齐本书此前章节的人物台词声线、市井对话质感与动作白描，坚决杜绝中后期文风脱离全书自生风格。
- **保事实**：润色过程中是否完整保留了伏笔线索、身体伤情、时间线数字？
- **破套式**：是否彻底清除了“不仅是……更是……”、“看似……实则……”假对比与段尾虚浮升华？
- **说人话**：是否已将“进行了攻击”、“给予了重创”等公文翻译腔替换为具象动作白描？
- **降成语/精破折**：是否消除了四字成语连环轰炸与“——”破折号泛滥？
- 正文字数严格达到 3000-5000 字标准（使用校验脚本硬性核验）。

## 二、自动化质检工具链与执行规范

每章正文完成后，必须运行单章综合一致性质检脚本：

```bash
# 综合质检与自动报告沉淀
python {skillBaseDir}/scripts/verify_chapter_consistency.py <章节文件路径> --project-dir <工程根目录> --auto-report

# 单章文本套式与精确汉字扫描
python {skillBaseDir}/scripts/scan_chapter.py <章节文件路径> --min-words 3000
```

- **BLOCKED**（退出码 1）：必须定位输出的 `issues` 具体段落，定向重写并再次复检，直至退出码为 0。
- **PASS**（退出码 0）：准予进入阶段 D 事实回写。
