# 小说写作原则

> 本文把四条通俗写作建议改写成写前与写中可用的问题。它们是启发式检查，不是评分项、硬性指标或统一风格模板；以当前作品设定、人物声口和用户要求为准。

## 1. 描写为故事服务

描写的价值在于让读者更清楚地看到人物处境、行动阻力、关系变化、情绪或后果。写环境时，优先选择会影响人物感知或行动的部分；写动作时，尽量让选择和反应自己显露人物；写心理时，保留真正改变判断或行动的关键一刻，避免把动作、情绪和结论连续解释三遍。

写完一段可问：

- 读者因此多知道了什么，或对谁、对局势有了什么新判断？
- 这段是否让行动、关系、情绪、氛围或节奏发生了有效变化？
- 若删去或压缩，是否会损失理解、情感、人物辨识或后续因果？

答案都是否定时，再考虑删改。不要把“服务剧情”缩窄成每段都必须加压：喘息、日常、幽默、迟疑和看似无用的细节，只要建立关系、呈现生活或形成节奏，就可以保留。也不要求用动作取代所有解释；简洁说明有时最清楚。

## 2. 用内在张力塑造人物

人物可以同时想要彼此冲突的东西，也可能在公开形象、真实需要和实际选择之间有落差。设计或书写重要人物时，可核对：

- **欲望**：此刻最想得到或完成什么？
- **软肋**：最怕失去什么，或什么会使其判断失准？
- **底线**：受压时愿意做什么，绝不愿做什么？底线是否可能被代价逼到边缘？
- **反差**：别人看到的形象与其私下真实、言行与需要之间，是否存在有来由的张力？

不必为每个角色填满四项，也不必人为制造反差。矛盾要从经历、处境、利益或关系中生长；人物会变化，但变化应有选择和代价支撑。配角拥有自身目标与局限，不只作为主角的工具。

## 3. 让对话参与行动

写对话前先想清这一场在做什么：交换或隐瞒信息、试探立场、争取资源、拒绝要求、修复或损害关系、逼出选择，或让人物用闲谈回避真正的问题。对话及停顿、打断、沉默、动作，都可以改变现场；纯粹轻松的闲聊也可用于建立亲近、日常感和节奏。

检查时可问：

- 这场谈话结束后，谁知道得更多、关系变了，或下一步行动被改变？
- 说话方式是否符合人物身份、关系、情绪和当下压力？
- 去掉一句后，信息、人物辨识、节奏或情绪是否受损？

没有变化不代表台词必然要删；若它有真实的生活、喜剧或节奏作用，可以保留。避免让所有人物都说成同一种机敏、完整、善于总结的口吻，也不要强迫每句台词都承担隐喻、伏笔或冲突。

## 4. 用开端和结局约束长篇大纲

长篇规划优先说清故事从什么局面开始、读者为何愿意跟下去，以及故事最终抵达什么情感与因果落点。结局可以开放或留有谜团，但应回应核心人物选择和主要代价；“情理之中”不等于必然圆满，也不要求预先锁死每个细节。

两端有了方向后，用关键节点连接中段。每个节点至少说明：发生了什么、人物为何这样选择、选择带来什么后果，以及它如何改变下一阶段。升级、反转可以使用，但不是固定节拍；中段可由调查、关系变化、失败、日常积累或后果扩散推进。发现中段散漫时，检查节点间是否缺少因果、代价或方向变化，而不是机械添加反转。

## 使用边界

- 规划阶段用这些问题检查因果、人物动机、情绪落点和长线方向，不因简写缺少感官、完整对白或动作细节而扣分。
- 正文阶段只把它们当作创作提示；审稿仍以 [唯一核心审查协议](review-core.md) 为裁决依据，不另设评分或门禁。
- 与题材、人物声口、专业程序或用户明确要求冲突时，以具体上下文为准；保留确有功能的慢戏、说明、重复、沉默与细节。
