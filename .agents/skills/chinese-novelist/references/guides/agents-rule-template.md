# 小说工程 AGENTS.md 规范与模板

> `AGENTS.md` 放置在小说工程根目录，是面向所有接入的 AI Agent（无论是 Claude Code、Codex、Antigravity、Cursor 还是其他本地 Agent）的**最高全局契约**。
> 它规定了 Agent 的读取权限、Token 预算控制、写前写中写后约束，确保任何 Agent 接手项目都能严格保持一致性。

---

## 标准 AGENTS.md 模板

```markdown
# 小说工程创作约束与 Agent 协作指南

## 1. 唯一权威设定源原则（Single Source of Truth, SSOT）
- **世界规则**：唯一权威源位于 `01-世界观/`。
- **人物基准与三级小传体系**：唯一权威源位于 `02-人物/`（`主角/`、`配角/{初始所属势力}/`、`辅助角色/{初始所属势力}/`）独立档案。
  - **核心铁律**：主角和配角都要有人物小传，理论上只要多次出现的人物都要设立小传！
  - **小传定位（冰山原则与合规基准）**：小传没必要所有的情节都在正文中提及，只是为性格和人物建立一个基础而已，后续合规性教研质检时作为基准输入对照核验。
  - `00-人物档案.md` 仅为只读编译快照，严禁手动直接在此修改人设。
- **剧情大纲**：唯一权威源位于 `03-剧情/`。
- **文风基准**：唯一权威源位于 `04-文风/`。
- **动态状态**：唯一权威源位于 `07-创作记忆/人物实时状态.md`。
- **多媒体资源库**：角色视觉素材存放于 `10-人物插画/`，剧情音频配乐存放于 `11-剧情音频/`（标准模式为 `人物插画/` 与 `剧情音频/`），由用户按意愿自由存放并在小传/正文中按需引用。

## 2. 渐进式读取协议（JIT Context Loading）
在开始撰写第 N 章时，**绝对禁止全量读取全工程文档**。
必须按以下顺序渐进加载，控制单次创作的参考上下文在 4000-6000 tokens 以内：
1. 【全局总则】读取本文件（`AGENTS.md`）
2. 【进度与状态】读取 `07-创作记忆/当前写作进度.md` 和 `07-创作记忆/人物实时状态.md`
3. 【任务卡】读取 `05-写作计划/章节任务卡/第{N}章-任务卡.md`（或当前分卷规划中对应小节）
4. 【写前小传核查与精准加载】核对本章参演人员，主角/配角/多次出现角色若缺少小传必先补齐建档；根据登场名单读取对应 `02-人物/主角/` 或 `02-人物/配角/{势力}/`、`02-人物/辅助角色/{势力}/` 下的独立小传（重点关注“行为逻辑”与“禁止偏离清单”）
5. 【相关专题】仅当本章涉及特定科技、地理或异象时，加载对应的单个 `01-世界观/` 专题文档
6. 【双源文风动态挂载与语态落点】读取 `03-文风基准.md` 的双源权重指示牌（核心铁律：文风不仅参考外部文本更深度参考小说正文，且小说正文越多参考自身权重越重）。按动态比例装载：① 外部反模式规约（外部权重）；② 本书自生黄金段落库 + 上一章结尾切片 800-1200 字（自身正文权重，成熟期达 80%~90%）。动笔前最后装入注意力头部的必须是正文语态。

## 3. 核心行为与认知铁律
- **小传冰山原则与性格基石**：小传是人物性格地基，正文无需全盘复述其生平，通过具象动作与抉择自然体现。
- **禁止全知视角的剧透**：角色只能依据其已知情报行动与思考。不得在主角心里透露读者已知但主角不知的情报。
- **尊重生理与环境约束**：角色行动受限于其当前的健康、伤病、装备余量及地理距离。
- **禁止机械降神与突兀开挂**：战斗力暴涨或局势逆转必须依托已有伏笔与代价。
- **严格去 AI 味**：遵循 `04-文风/禁用表达与常见问题.md`，坚决去除假大空形容词和套路化句式。

## 4. 写后审稿与事实回写（Fact Writeback）
撰写完成后，严禁直接跳过收尾：
1. 先在 `08-审稿/` 输出单章审校单（以小传为输入核查人设行为逻辑合规性、伤病继承、情报边界）。
2. 将正文保存至 `06-正文/第X卷/第YYY章.md`。
3. 事实回写：更新 `07-创作记忆/人物实时状态.md`、`事件时间线.md` 与 `伏笔兑现记录.md`。
4. 运行 `python sync_novel_memory.py . --compile-views` 刷新只读兼容索引、章节摘要与下一章双源文风权重指示牌。
5. 文风持续沉淀：若本章存在高水准代表性段落（高张力动作白描/神韵对话/生活毛边感），择优沉淀入库。
```

- **第三方视角插章**：视角人物及关键情节执行者也必须先建小传；按首次正式登场势力归档，未知势力不臆断。编号章/插章遵守相同档案门禁。
