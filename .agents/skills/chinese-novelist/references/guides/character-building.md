# 人物塑造指南

好的人物是故事的灵魂。读者记住的是人，不是情节。

> 人物档案模板请使用 [character-template.md](character-template.md)（Phase 2 创建时使用）。本文档聚焦于**在写作过程中**塑造人物的技法。

---

## 核心原则：矛盾创造深度

真实的人是复杂的，充满矛盾。矛盾是人物成长的**发动机**。

**有效矛盾示例：**
- 雷厉风行的女警长，回家后对着亡夫的照片说话
- 满口仁义的书生，暗中替人写休书赚银子
- 冷血杀手，每天给流浪猫带鱼
- 最不信命的人，抽屉里藏着一张求来的护身符

**无效矛盾**：为矛盾而矛盾，与人物核心无关。

## 侧面揭示技法

不要直接陈述性格，通过行为展示。这是"展示而非讲述"在人物塑造上的核心应用。

### 用动作替代标签

| 直接陈述（弱） | 侧面展示（强） |
|----------------|----------------|
| 他很愤怒 | 他捏碎手中的纸杯，碎片扎进掌心也没松手 |
| 她很紧张 | 她反复调整眼镜位置，第三次了 |
| 他很傲慢 | 他从不直视下属的眼睛，对话时总是看窗外 |
| 她很善良 | 她偷偷喂了三年流浪狗，谁也没告诉 |
| 他很孤独 | 电视永远开着，他从来不看 |

### 用选择揭示本质

人物在压力下的选择，比任何描述都有说服力。

**示例：**
> 火灾现场，他可以救名画，也可以救那只猫。他抱起了猫。
> 不需要写"他善良"，这个选择已经说了。

### 用习惯暴露真相

反复出现的小习惯是人物的无意识自我暴露。

- 紧张时摸无名指（曾经戴过戒指？）
- 总是坐在背靠墙的位置（缺乏安全感？）
- 说话时避免眼神接触（隐瞒什么？）
- 对每个服务员都说谢谢（教养？还是内疚？）

## 主角塑造

### 主角必须有

- **明确目标** - 他想要什么
- **强大动机** - 为什么想要
- **可共情性** - 读者能理解他的感受
- **成长空间** - 故事中会改变

### 主角原型

| 类型 | 特征 | 故事作用 |
|-----|------|---------|
| 英雄型 | 勇敢、正义、利他 | 战胜外在威胁 |
| 成长型 | 从弱小到强大 | 克服内在缺陷 |
| 反英雄型 | 道德灰色、复杂 | 挑战传统道德 |
| 平凡型 | 普通人卷入非凡事 | 读者代入感强 |

### 缺陷致命化

主角必须有缺陷，缺陷在关键时刻导致失败。没有缺陷的角色不会成长。

| 缺陷 | 导致的失败 | 成长方向 |
|-----|----------|---------|
| 傲慢 | 低估对手，落入陷阱 | 学会倾听 |
| 信任问题 | 拒绝帮助，孤立无援 | 学会信任 |
| 完美主义 | 无法及时行动，错失机会 | 学会接受不完美 |
| 复仇心 | 被利用，失去理智 | 学会放下 |
| 逃避 | 问题越滚越大 | 学会面对 |

## 反派塑造

好反派不是坏人，是**信念不同的人**。

### 好反派的标准

- **强大可信** - 不应该是草台班子
- **有自己的逻辑** - 他相信自己在做正确的事
- **与主角有深层联系** - 不是单纯为了作恶
- **揭示主题** - 挑战主角的信念

### 反派动机层次

**浅层动机**（不够）：
> "我想毁灭世界" → 乏味

**中层动机**（及格）：
> "我失去了一切，世界对我没有意义" → 可理解但单薄

**深层动机**（有力）：
> "我的女儿死于一种本可治愈的病，但药厂为了利润延迟了上市。这个世界不值得被拯救。" → 读者虽然不认同，但能理解

### 反派与主角的镜像关系

最好的反派是主角的**黑暗镜像**——如果主角走了另一条路，就会变成他。

```
主角：失去家人后选择保护他人
反派：失去家人后选择毁灭一切
同一起点，不同选择。
```

## 配角的功能性

配角存在的唯一理由是**对主角产生作用**。

### 配角类型

| 类型 | 功能 | 注意 |
|-----|------|------|
| 导师型 | 指引主角，传递信息 | 必须有自己的盲区 |
| 盟友型 | 协助主角，提供支持 | 不能只是工具人 |
| 搞笑型 | 缓解紧张 | 在关键时刻也能严肃 |
| 叛徒型 | 制造转折 | 背叛要有前期铺垫 |

### 配角原则

- 删除"只是存在"的角色
- 每个配角必须有明确作用
- 避免刻板印象（除非是有意为之）

## 人物关系设计

### 关系动态变化

好的关系会随故事发展，不是静态的：

```
第一章：陌生人
第三章：不情愿的盟友
第五章：建立信任
第七章：背叛/考验
终章：真正的友谊（或决裂）
```

### 关系揭示层次

逐步揭示关系深度，不要一次性全部暴露：
- **表层**：表面互动
- **中层**：共同经历后的默契
- **深层**：真实感受/秘密

### 高戏剧潜力关系

| 关系类型 | 戏剧潜力 | 经典模式 |
|---------|---------|---------|
| 亦敌亦友 | 高 | "我知道你在利用我，但我需要你" |
| 禁忌之爱 | 高 | 身份/立场对立，但无法控制感情 |
| 师徒关系 | 中 | "教会徒弟，饿死师父"的潜在张力 |
| 兄弟竞争 | 中 | 同一起点，不同选择，此消彼长 |

## 人物出场设计

### 首次出场原则

有效的出场方式：
- **行动中** - 展示能力或性格
- **冲突中** - 立即建立关系/对立
- **误解中** - 建立悬念

### 出场示例对比

| 无效出场 | 有效出场 |
|---------|---------|
| 李明，28岁，是一名侦探。他走进办公室。| 李明跨过警戒线，警官试图拦住他。"市刑警队，李明。"他亮出证件，径直走向尸体。|
| 美丽的女孩坐在窗边，她叫小红。| 她已经三天没睡了，咖啡杯里的液体在颤抖。当门铃响起时，她几乎把杯子摔在地上。|

**避免**：镜子自照描写外貌、简历式介绍、无意义的日常活动。

## 人物一致性检查

角色行为必须符合已建立的性格。

**检查问题：**
- 这件事符合他的核心价值观吗？
- 以他的背景，会有这样的反应吗？
- 他的恐惧会如何影响这个决定？
- 他的缺陷会导致他犯什么错？

**例外处理：**
- 如果角色"不符合性格"行事，必须有原因
- 解释应该在相同/下一章提供
- 可以是成长的标志（角色克服了缺陷）

## 长篇小说人物层级管理：主角、配角与辅助角色+章节

在长篇创作中，出场角色随着剧情展开而不断增多。如果不加以严格的层级归类与写前控制，极易出现“人物台词走样、关键信息前后矛盾、路人突然变成主角救场、后续想找某个角色查不到”等恶性问题。

为此，Skill 制定了**三级分类管理体系**、**小传底层定位哲学**与**写前角色完备性核验机制**。

### 1. 核心法则：主角、配角与多次登场人物全员立传

> ⚠️ **核心铁律**：**主角和配角都要有人物小传，理论上只要多次出现的人物都要设立小传！**

- **必须建档（生成独立小传）的判定标准**：
  1. **主角与核心/重要配角**：全员必须建档，拥有完备独立小传；
  2. **多次出现/后续复现角色**：理论上只要在小说中多次出现（或大纲预设后续章节/分卷还会再次登场，哪怕只是周期性露面），都必须设立独立小传；
  3. **关键情节推动者**：在本章承担了重大剧情转折、提供了关键线索/证物/技术支持、或者触发了重大危机的角色；
  4. **有具体姓名与深度交互者**：拥有具体名字、鲜明身份标签、独特技能或言行风格，与主角/核心团队产生了实质性言语对抗或合作；
  5. **特定阵营常驻功能角色**：如防区军医、驻地老工匠、特定哨卡长官、黑市情报商、特定追击小队队长等。
- **免建小传的唯一特例（纯一次性龙套）**：
  - 仅限纯背景过客、无名背景板，且全书绝无二次登场可能的路人（如“无名小二端上一碗水即退下”、“城门守卫查验路引后挥手放行”等）。

### 2. 小传定位与使用哲学：冰山原则 × 合规基准

> 💡 **核心认知**：**小传没必要所有的情节都在正文中提及，只是为性格和人物建立一个基础而已，后续合规性教研的时候可以当做输入。**

1. **冰山原则（无须正文全盘复述）**：
   - 小传是人物隐没在水面之下的“八分之七”冰山（成长烙印、童年创伤、行事成因、隐秘执念与生理习惯）。
   - **绝不需要在正文中事无巨细地交代小传里的每一段生平**，切忌写成机械的“人物简历介绍”或大段背景说明文。
   - 正文只需通过具象的动作、本能反应、两难抉择和台词留白，让读者感受到人物水面之下的沉重底色。
2. **性格与动机的坚实地基**：
   - 小传的唯一首要目的，是为人物建立连贯、自洽、厚重的**性格基石与行为底层逻辑**。
   - 有了小传，人物在面对利益诱惑、生死危机时的反应才是真实可信的，绝不会沦为剧情的提线木偶。
3. **合规性校验（教研质检）的权威输入源**：
   - **小传是后续合规性校验（合规性教研 / Quality Gate 审查）的核心基准输入**。
   - 每章质检与全书校验时，系统会将人物小传作为输入源，与正文进行严格的合规性核对：
     * 核对角色当前言行是否符合小传设定的性格底色与心理机制；
     * 核对关键决断是否符合其底层动机与牺牲红线；
     * 核对台词风格是否符合其身份背景（杜绝人人说教）；
     * 严格检查正文是否违背了小传中的【禁止偏离清单】（硬性拦截 OOC 人设崩塌）。

### 3. 三级分类与命名组织规范（方便快速检索）

小传文档统一按照 **主角 / 配角 / 辅助角色+章节** 模式区分：

| 类别 | 归档路径 | 命名规范 | 模板与核心关注 |
| :--- | :--- | :--- | :--- |
| **主角** | `02-人物/主角/` | `[角色名].md` | [十维深度主档模板](deep-character-template.md)，全员立传，重点关注行为底层逻辑、创伤点与禁止偏离清单 |
| **配角** | `02-人物/配角/{初始所属势力}/` | `[角色名].md` | 十维或高阶主档，全员立传，重点关注与主角关系网络、阵营利益、牺牲底线与命运宿命 |
| **辅助角色** | `02-人物/辅助角色/{初始所属势力}/` | `第XXX章-[角色名].md` 或 `第一卷插章NNN-[角色名].md` | [辅助角色精悍小传模板](deep-character-template.md)，**多次出现角色必立小传**，以首次登场章节命名，重点关注功能使命、性格底线与后续复现预设 |

**按「初始所属势力 + 首次登场编号章或插章」命名**：首次正式登场时的实际阵营为准，未知存入 `初始阵营未确认/`，角色后续更换归属只更新小传履历不迁档。插章主视角、关键功能角色和跨场景复现的匿名角色一样需要独立小传；一次性无名群演可豁免。

**按「辅助角色+章节」命名的核心优势**：
1. **时间线自然排序**：在文件列表中按章号自然聚拢（如 `第001章-边民老猎户.md`、`第002章-友邻阵营联络哨长.md`），一眼看出每个角色是在哪一章初次引入。
2. **写前秒查防重名**：后续章节写到相同场景或需要寻找老面孔时，按章节或关键词能瞬间秒查，绝不出现“同一个人前后两章名字不同”的低级失误。
3. **精准溯源复用**：当第 20 章需要召回第 1 章出场过的老兵或工匠时，直接读取对应章节小传，立即继承其伤病、脾气、语言口癖与道具存量。

### 4. 每章写前角色盘点与小传补齐四步法

在每一章正文动笔前，必须严格执行写前角色四步法：
1. **盘点名单**：查看当前章任务卡（`05-写作计划/章节任务卡/第{XX}章-任务卡.md`）与大纲，列出本章出场的所有参与人员；
2. **核对小传**：对照 `02-人物/`（或 `00-人物档案.md`），检查谁已有小传、谁尚未建档；
3. **识别补齐**：发现主角、配角或多次出现角色缺少小传，**严禁跳过，动笔前必须先补写其小传**；
4. **归档登记**：按 主角/配角/辅助角色+章节 归档至对应目录，并在 `人物总表.md` 与 `人物实时状态.md` 登记，执行 `sync_novel_memory.py --compile-views` 刷新只读速查。小传将作为后续该章合规性质检核验的权威输入。
