## 共有的保留原则

1. 保住时间、数字、行动主体、伤情、物资、否定/情态、人物声口和既有伏笔；资料不足不补造。
2. 一个根因只记录一次；脚本和词频仅协助定位，再由原文上下文、损害、反证和净收益裁决。
3. 看起来“像 AI”不等于作者身份鉴定；有效的短句、重复、留白、慢场景、真实手续及文学修辞允许保留。
4. 默认主动审查时，仅对已确认且正净收益的局部改动自动修订；没有正收益时保留，修改后复验，轮次由核心协议统一限定。
