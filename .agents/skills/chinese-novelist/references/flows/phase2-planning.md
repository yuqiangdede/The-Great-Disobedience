# 第二阶段：规划 + 二次确认

> **前置条件**：本阶段使用 Phase 1 Layer 3 用户确认的小说标题与 Layer 2 确定的架构模式（`deep` 或 `standard`）。标题信息从对话上下文中获取，用于命名项目目录、写入大纲文件头和写作计划 JSON。

---

## 分支 A：深度模块化架构（architectureMode: "deep"）

当用户选择或推荐采用「深度模块化架构」时，执行本分支：

1. **创建工程目录**：`./chinese-novelist/{YYYYMMDD-HHmmss}-{Layer 3 确认的标题}/`
2. **初始化深度工程脚手架**：
   可直接调用初始化脚本：
   ```bash
   python {skillBaseDir}/scripts/init_novel_workspace.py <项目目录> --title <标题> --mode deep --genre <题材>
   ```
   脚手架将自动生成标准工程目录与核心模板（含多媒体资源库）：
   - `AGENTS.md`（全局创作约束、JIT 渐进加载与写前角色小传核验指南）
   - `README.md`
   - `01-世界观/`（总纲、历史与时间线、地理与边境、阵营组织、战力规则、武器科技、经济社会、异常威胁）
   - `02-人物/`（分级人物小传目录）：
     - `02-人物/主角/`（存放主角独立主档）
     - `02-人物/配角/{初始所属势力}/`（存放核心配角、重要反派、深度队友主档）
     - `02-人物/辅助角色/{初始所属势力}/`（存放次要/功能性角色，以 `第XXX章-角色名.md` 或 `第一卷插章NNN-角色名.md` 命名）
     - `人物总表.md`（三级分类总览与出场矩阵）
     - `人物关系与冲突.md`（内部羁绊与外部冲突矩阵）
   - `03-剧情/`（全书主线、分卷因果大纲、伏笔与秘密、终局命运）
   - `04-文风/`（文风总规范、原创文风样例、去AI味负面清单）
   - `05-写作计划/`（章节规划总表、分卷细目、单章任务卡）
   - `06-正文/`（分卷正文目录）
   - `07-创作记忆/`（当前进度、人物实时状态表、事件时间线、伏笔兑现记录、变更日志）
   - `08-审稿/` 与 `09-归档/`
   - `10-人物插画/`（角色视觉立绘、肖像与高光情节插画，供用户按意愿自由存放扩展）
   - `11-剧情音频/`（章节朗读配音、广播剧片段与氛围配乐，供用户按意愿自由存放扩展）
3. **权威设定深度生成与完善**：
   - **人物层级建档（主角配角全员立传，多次登场必建小传）**：
     - **核心原则与定位**：**主角和配角都要有人物小传，理论上只要多次出现的人物都要设立小传！小传没必要所有的情节都在正文中提及，只是为性格和人物建立一个基础而已，后续合规性校验（教研质检）的时候可以当做输入。**
     - **主角小传**：在 `02-人物/主角/` 独立建档，采用 [deep-character-template.md](../guides/deep-character-template.md) 模板，写明 10 个维度，重点落实**行为逻辑**与**禁止偏离清单**。
     - **配角小传**：在 `02-人物/配角/{初始所属势力}/` 独立建档，写明与主角的关系矩阵、阵营立场与牺牲底线。
     - **辅助角色小传**：对第一卷早期登场的功能角色与多次出现角色，在 `02-人物/辅助角色/{初始所属势力}/` 采用 `第XXX章-角色名.md` 或 `第一卷插章NNN-角色名.md` 格式建档。
     - **插章人物同级建档**：视角人物、关键功能人员与多场景复现角色即使仅在非编号插章出现，也必须在详写前建独立小传；人物概要、简写、任务卡列初始势力与小传路径，未知势力放 `初始阵营未确认/`，严禁凭空造所属。
     - **人物总表**：在 `02-人物/人物总表.md` 分区登记主角、配角与辅助角色（按章节）。
   - **世界观八大主档填充**：参考 [deep-worldbuilding-guide.md](../guides/deep-worldbuilding-guide.md) 填补本题材核心公理。
   - **分卷因果剧情规划**：参考 [deep-plot-volume-guide.md](../guides/deep-plot-volume-guide.md)，第一卷大纲必须回答**因果三问**（发生什么、为何选择、不可逆后果）。
   - **单章任务卡与动态底表**：
     - 生成第 1 章任务卡 `05-写作计划/章节任务卡/第001章-任务卡.md`，明确本章出场人物（主角、配角、辅助角色），并列明小传核查清单；
     - 生成 `07-创作记忆/人物实时状态.md` 初始底表。
   - **文风认知蒸馏（Nuwa 双源动态加权表达 DNA）**：若用户提供了参考文档或指定作家，根据 [nuwa-style-distillation-guide.md](../guides/nuwa-style-distillation-guide.md) 调用 `python {skillBaseDir}/scripts/distill_style_dna.py` 生成 `04-文风/文风DNA蒸馏档案.md`（带动态权重指示盘），提炼心智模型、决策启发式、表达 DNA（量化句长、动词指纹）与反模式，并录入 500-800 字黄金样章写入 `04-文风/原创文风样例.md` 作为全书语态锚点。明确确立“文风不仅参考外部文本更深度参考小说正文，且正文越多参考自身权重越重”的全书演进法则。
4. **编译生成只读兼容视图**：
   运行编译命令：
   ```bash
   python {skillBaseDir}/scripts/sync_novel_memory.py <项目目录> --compile-views
   ```
   自动从 `02-人物/` 提取分级信息，并结合已写正文与文风源生成 `00-人物档案.md`、`01-大纲.md`、`03-文风基准.md`（含双源文风动态权重指示牌）、`99-章节摘要.md` 作为只读快照与索引，供跨阶段工具链无缝调用。
5. **初始化 `02-写作计划.json`**：正文路径映射到 `06-正文/第一卷/第001章-[标题].md`。

## 分支 B：标准轻量架构（architectureMode: "standard"）

当选择标准轻量架构时，按原有经典扁平结构执行：

1. **创建项目文件夹**：`./chinese-novelist/{YYYYMMDD-HHmmss}-{Layer 3 确认的标题}/`
2. **生成人物档案**：创建 `00-人物档案.md`，使用 [character-template.md](../guides/character-template.md) 模板，参考 [character-building.md](../guides/character-building.md) 规范，清晰划分：
   - `## 一、主角`
   - `## 二、配角`
   - `## 三、辅助角色（按登场章节归类）`
   落实“主角和配角都要有人物小传，理论上只要多次出现的人物都要设立小传”的原则。明确小传无须在正文中全盘复述其生平情节，重点是建立性格底色地基，并在后续合规性校验（教研质检）中作为基准输入。
3. **生成大纲**：创建 `01-大纲.md`，使用 [outline-template.md](../guides/outline-template.md) 模板，参考 [plot-structures.md](../guides/plot-structures.md) 填入完整的章节规划。
3.2. **创建多媒体资源目录**：创建 `人物插画/` 与 `剧情音频/` 专属文件夹，供用户按意愿自由存放角色立绘与剧情音频配乐。
3.5. **生成文风基准（融入 Nuwa 双源动态加权表达 DNA）**：创建 `03-文风基准.md`。若提供了参考文本，调用 `distill_style_dna.py` 蒸馏文风指纹、量化句式律动、基准段落、负面清单，并确立“正文越多参考自身权重越重”演进指标。
3.7. **创建章节摘要文件**：创建空的 `99-章节摘要.md`。
4. **生成写作计划**：创建 `02-写作计划.json`。

---

## 规划确认与模式选择（双分支共用）

完成规划生成后，执行以下两步：

**1. 展示规划摘要并请求确认**

向用户展示规划摘要（小说名称、总章数、目标字数、主要人物、文风基准来源）并请求确认。

**2. 写作模式选择**（用户确认规划后）

使用 `AskUserQuestion` 询问：

```
Question: 选择写作模式
Options:
- 逐章串行（主 Agent 自己逐章写，全程无中断，适合短中篇）
- 子Agent并行（分批派生子 Agent 并行写作，大纲驱动连贯性，适合中长篇）
- Agent Teams（Claude Code 多 Agent 协作模式，Agent 间可通讯，需手动开启）
```

用户选择后：
- 更新 `02-写作计划.json` 的 `writingMode` 字段
- 更新 `status` 为 `"in_progress"`
- 进入第三阶段：疯狂创作 → 详见 [phase3-writing.md](phase3-writing.md)
