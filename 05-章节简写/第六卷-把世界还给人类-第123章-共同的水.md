# 第六卷·第123章《共同的水》简写

状态：待作者审阅；正文未写。

暴雨逼近，上游希望提前泄水保护水库和电站，下游担心河堤与低地住房承受不住。各地独立测站读数矛盾，工程师发现基准尺不同，只能解释部分差异，真实趋势仍不确定；一处测站又被雨水冲偏，旧值不能支持任何一方。模型给出多种局部方案，却补不上未测河段，也不能替居民决定哪片区域承担淹水风险。许砚要求并列展示输入来源、置信区间和边界条件，黎照让各方列出受影响村庄、道路和撤离时间，并记录各地选择与预期损失。上游提议边放水边复测，下游担心水先于居民撤离；联合小组携两套基准尺外出，天气和通信让回报时间难定。各方先启动撤离准备，但上游不肯等待、下游不肯盲目放水，泄洪决定仍未作出。

上游提出边撤离边放水，下游认为居民可能来不及离开。通信断续让联合组回报时间不定，黎照只先记录各方预期损失并启动撤离准备；准备工作不能被误写成泄洪方案已经获批。

联合组出发前确认两套基准尺各自的校准记录，避免把携带工具本身当成测量结果可靠的证明。

本章钩子：联合测量组尚未返回，水库水位已接近上游设定的行动线。
