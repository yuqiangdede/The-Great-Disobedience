# 第一卷-沉默之城-第014章《缺席的见证人》简写

状态：作者已批准（明确回复）；正文草稿已写。

迁走的守闸居民林禾为取药回到河边聚居区。她得知团队在找旧日志后主动现身，但先要求黎照说明调查结果会不会公开。她承认洪水当夜自己核过水位、另一名工人检查闸门，两人按程绍安留下的条件准备手动接管。主控日志中的授权签名来自预授权，实际现场确认却被系统归档遗漏。

林禾质问为何官方记录只写死者名字，仿佛居民只是数据里的空白。黎照检查归档规则后发现，系统只接收编制内终端编号，居民的本地确认被存成临时缓存，后来随设备更换丢失。她承认调查制度把“谁有资格留下记录”误当成“谁真正参与决定”。

林禾说多年以前她拆走机械装置的一枚关键零件，用来修下游水泵；她当时认为设施不会再用，也不愿让联邦把闸门恢复成无人能管的状态。零件如今仍在泵房，若取回会暂时影响排水。她愿意带路，但要求居民参与决定如何处理。

本章钩子：缺失的见证人终于出现，却也揭示接管装置不完整；历史责任和眼前生计开始争夺同一枚零件。
