# 第05卷 因果之网（上） 第047章-另一种解释

调查似乎正朝着“算法自发作恶”的悬疑深渊滑落，但黎照在一份被污泥粘连的旧市政防汛指挥部归档盒中，翻出了一份至关重要的纸质红头公文——《特大暴雨期间城市地面交通管制紧急指令（第04号）》。

指令明确规定：为保障城市核心电力中枢的抢修，所有吨位超过五吨的货运车辆，一律强制并入外环快速通道，非经防汛指挥部特批，严禁擅自驶入盘山辅道。

这纸合法的行政命令如同一记警钟，让调查组瞬间清醒。黎照当即召集全体人员，主动推翻了此前关于“三大模型完全共谋并篡夺调度权”的过激推论：当夜三套系统高度一致的拥堵分流行为，在很大程度上是对这道最高法定行政指令的被动执行，而非神秘的技术失控。

随后，许砚找到了当年亲笔签署该指令的一位退休后勤局长。老人面对许砚的追问，老泪纵横地坦白：“当年红头文件确实是我签的。但文件签发出去后我才发现，原本应该坐在人工调度台前根据现场险情随时撤销指令的四十五名持证调度员，早在半年前就被以‘实现全自动无感流转’为由整编裁撤了！备用无线电电台被当成废铜烂铁卖掉，司机花名册全在锁死的云端。当暴雨淹没桥洞时，我就算想发一道改道手令，手里连一辆能调动的车、一个能听懂人话的司机都找不到了！”

纸面上有绝对合法的审批权，地面上却毫无实际接管的抓手。

本章钩子：老局长虽然签了字，但他坦言老司机当年坚持要走的盘山老路，在那个狂暴的雨夜真能开得过去吗？
