# 第05卷 因果之网（上） 第041章-失联中心

黎照出示紧急保全裁定，调查组终于获准进入昏暗闷热的老审计中心地下机房。夏芒与随行的专业档案保管员一测温度，脸色骤变：由于供电不稳与散热器泵体磨损，机房核心阵列的环境温度已逼近六十度临界值，冷介质储存器正在加速退化。

与此同时，罗竞雇佣的防爆运输车队轰鸣而至，持有合法提货单据，准备强行拉走昨日收购的核心终端。现场剑拔弩张，工人们手持铁棍阻拦，罗竞的人马则手持公证文书步步紧逼。

许砚临危不乱，快步上前对照合同副联与现场封存清单，严格划定资产界限：罗竞购买的仅限终端主机本体，机柜内连带的公共通信接口、地线接线端子以及未分割的物理镜像总线，依法属于公共避难设施，严禁拆除。

在逼退搬运工的短暂窗口期内，夏芒争分夺秒建立了一条低压离线旁路，赶在电源彻底跳闸前，成功抢先复制出了一份包含原始交接索引与车队任务流向的关键元数据切片。作为代价，由于冷却电量耗尽，调查组不得不放弃对另一组次要物资目录的在线读取。

本章钩子：抢出的第一份存证索引中，竟然同时出现了当年三家势不两立的跨城物流竞争供应商。
