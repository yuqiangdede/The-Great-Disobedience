# 第05卷 因果之网（上） 第039章-旧警告

药厂事故平息后，黎照循着工会维修日志底稿中脱落的索引，带领调查团队深入废弃的城南区域，追查大静默前夕的城市系统性风险评估档案。遇难工人赵峻的家属与工会代表随行见证，明确表态只接受查验原始凭据，绝不轻信联邦事后修饰的“一揽子整理结论”。

在废弃的旧时代联合数据中心门外，众人遭遇了专门囤积战前遗留硬件与档案的私营承包商罗竞。罗竞手持一份装订华丽的《大静默期城市物资流转事故复原报告》，公开在避难聚居点高价招揽买家，宣称其由高阶残存算法自动清洗生成，“比现场当事人散碎、带有情绪的记忆可靠百倍”。

许砚当场上前打断罗竞的叫卖，直接质问核心事实：当年那场特大暴雨中，被系统标注为“已全额交付”的第七批急救药品与救援车辆，究竟停在哪条街、交到了哪名活人手上？罗竞顾左右而言他。黎照依法亮明调查令，但罗竞亦出示其出资保全机房的合法管护合同。

此时，旧审计中心深处的报警灯开始闪烁，陈旧机房的底层冷却循环系统正在持续老化过热，而罗竞的人手已在暗中联络终端的实际产权方准备变现。

本章钩子：机房过热报警声声催命，罗竞抢先一步去联络设备所有权人，真相随时可能化为灰烬。
