# 第05卷 因果之网（上） 第040章-档案的价格

商业竞争以极其现实的方式展开。罗竞依据早年与破产数据托管公司签订的维保协议，赶在调查组办妥行政调阅手续之前，合法斥巨资从一名穷困潦倒的旧系统资产清算人手中，买断了一台存有大静默前夕核心调度日志的关键离线终端。另一位坚守职责的留守保管员因反感罗竞的垄断倒卖，拒绝交出配套的密码密钥与离线介质。

许砚眼睁睁看着关键硬件被罗竞的搬运工贴上封条装箱，但他并未冲动强夺。他深知在战后重构的秩序中，践踏产权只会让调查陷入非法泥潭。许砚转而协助黎照，依照法定程序核验清算人出具的资产转让交接副联，精准锁定了那台终端的物理序列号与出库去向；同时，黎照依法查封了机房的辅助接口与不可移动的只读镜像母盘，防止罗竞私自转移原始介质。

各方各执一词，围绕这批档案的实际归属与调阅权限寸步不让。罗竞在第一回合凭借雄厚的资金与敏锐的商业嗅觉暂时占了上风，但他很快发现，没有活人密码与真实的调度副联，这台昂贵的铁盒子根本吐不出完整的证据链。

本章钩子：三大跨城事故在目录中被列为同一索引，但核心数据母盘却在当夜面临被秘密转运的危机。
