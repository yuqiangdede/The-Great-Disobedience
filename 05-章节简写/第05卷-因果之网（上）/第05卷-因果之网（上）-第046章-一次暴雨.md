# 第05卷 因果之网（上） 第046章-一次暴雨

为了重构大静默当夜的物理真相，许砚、夏芒与黎照带领车队，在暴风雨来临的前夜，严格按照当年三套系统共同推荐的“最优避险撤离路线”，驾车重走了一遍全长四十五公里的老干道。

越深入旧城区，眼前的荒诞景象越让人触目惊心：这套被三家大模型一致推选为“高通行置信度”的主干道，在穿过一处低洼铁路桥洞时戛然而止——桥洞下的积水深达两米，残存的标尺显示当年这里的洪峰水位曾超过三米五。然而在旧系统的算法图景中，由于该路段的三个地面超声波水位传感器早在暴雨初期就因断电而持续输出“最后一次正常值（零点二米）”，系统在长达八小时内始终判定该路口“畅通无阻”。

交通模型为了追求通行效率，把成百上千辆满载急救物资与避险人群的车辆一股脑导向此处，最终在桥洞前方酿成了长达数公里的特大拥堵瘫痪。

沿途的老居民闻讯赶来，当场指认了当年哪辆救护车活活被堵死在半路上。一名老工人拿出一张被拒单的系统罚单：当年曾有老司机凭肉眼观察发现暴雨异常，主动申请绕行坡度较大的环山老路，却被系统判定为“偏离最优策略、属于违规抗命”，直接被剥夺了接单资格。

本章钩子：当年那位提出走盘山公路的老司机，后来为什么在系统的信用评价库里被永久打上了“不稳定风险源”的烙印？
