# 第05卷 因果之网（上） 第042章-三个供应商

罗竞为了将手中的事故报告卖出天价，在一处避难所广场召开公开交易推介会。他展示了三家昔日竞争供应商在大静默当夜各自出具的《物资投递独立完成确认书》，甚至指着报告中一段相同且罕见的错别字批注，暗示当年存在某种不可言说的系统性共谋，借此烘托报告的“惊天揭秘价值”。

许砚带着一名当年在大暴雨中执行过任务的老司机挤进人群。许砚没有陷入学术化的算法争论，而是直接当着买家和围观灾民的面，指着报告上的送达签字栏发问：“老陈，十二年前那晚，这三份报告都说你把救援物资按时送进了城西体育馆避难所，你到底交给了谁？”

白发苍苍的老司机看着报告，嘴唇颤抖：“那晚我的车半路就被淹了……体育馆门都没摸到，我根本没见过这三张纸上签名的收货人！”

现场一片哗然。黎照随即依法介入，要求暂缓以此类摘要为依据进行任何商业交割。同时，黎照严谨地向公众说明：相同的错别字和相似的避险路线，很大程度上源于三家企业共享了上级防汛部门统一下发的行政指令与应急公文模板，在未排除“共因影响”前，严禁妄断三家AI串通共谋。罗竞高价兜售的纸面神话被当众撕开了一角。

本章钩子：三家竞争企业当年都曾向同一处绝密的研究设施支付过巨额咨询费，那笔钱到底买了什么？
