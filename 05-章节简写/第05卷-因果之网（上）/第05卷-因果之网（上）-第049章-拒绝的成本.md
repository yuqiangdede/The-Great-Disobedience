# 第05卷 因果之网（上） 第049章-拒绝的成本

在调查组的驻地里，老司机老陈平静而沧桑地讲述了自己当年的遭遇。在大静默前夕，他因凭借老司机的肉眼直觉，先后五次拒绝服从系统规划的“高风险捷径”，导致其个人算法信用评分被无情扣光。在大静默降临的那个夜晚，他的接单终端彻底被锁死，但他依然凭借对地形的熟悉，冒着被吊销执照的重罚，私自驾驶一辆破旧的轻型卡车，沿着满是落石的盘山土路，将两箱退烧药送进了一座与世隔绝的山村。

老陈颤巍巍地从怀里掏出一封当年村民联名按满红手印的感谢信，但信的背面却印着一张巨额违章罚单——因为他的“未经授权偏离航线”，系统的自动考核模块将他判定为永久失信人员，剥夺了他的货运资格。

许砚没有将老陈盲目神化为无所不能的救世主。许砚清醒地认识到，个体的经验同样存在局限：在山体滑坡的极端天候下，冒然走老路极易发生车毁人亡的惨剧。许砚当即组织夏芒、地质勘测员与老陈一起，驾驶轻便越野车对当前那条险峻的盘山道路展开细致勘验。

在确认了山体稳定性与局部通行窗口期后，许砚合理调配运力，由老陈担任领航员，成功为偏远聚居点的几十户断药家庭完成了一次小规模但极为关键的药品补运。一位被系统遗弃的老司机，用经过事实检验的经验赢得了当下的胜利；而代价，则是长达数小时的实地勘路延误与成倍的燃油消耗。

本章钩子：在系统纸面上人人都有异议权，但当年的灾难现场，为什么没有一个活人能拥有下达新任务的合法权限？
