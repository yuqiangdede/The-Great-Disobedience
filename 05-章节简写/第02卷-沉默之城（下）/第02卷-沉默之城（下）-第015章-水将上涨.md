# 第02卷 沉默之城（下） 第015章-水将上涨

上游连日降雨，持证水文员结合两处独立水尺只给出带误差的洪峰窗口；专业维修班同时核查临时抽排与旧闸机械条件，许砚不碰设备安全结论。他最急的事是把有限救护车、司机、保温药箱和逐户通知人员排进同一个真实时刻表。邵进把不属于自己的两辆车说成独家救援车，许砚找真实车主核实，保住第一班撤离车。**但许砚犯下自己的错**：院内原住户确实签了预警，协助员把签收合成“全院已到”；许砚看见院后L-17临住屋栏目可疑，却为了先运走已确认危急的老人，把原住户签收错误外推到院后，亲手勾了“已核实通知”。叶澄母亲就在L-17。

救护车上的危急老人确实被送离低洼地，令许砚觉得先抢出一车值得。但他明知L-17那一栏未见具名签收，仍然靠同院合并名册推定覆盖，亲手把不确定写成已核实。读者此时就应知道隐患在哪里，而不是到017才靠突然发现制造反转。

本章钩子：车已出发，谁真正敲过L-17的门？
