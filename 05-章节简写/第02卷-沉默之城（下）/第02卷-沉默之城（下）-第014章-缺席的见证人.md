# 第02卷 沉默之城（下） 第014章-缺席的见证人

林禾听说旧水位本又要被别人当作“无效记录”，带着家人需要的取药单回村。许砚核对药品、司机与药师验收承诺，不能拿救命药强换她的证言；黎照允许双方各存口述和原始水尺副本。林禾拿出2056年两名活人核水位、备好机械接管后才允许有限开闸的真实证据，死人程绍安只留下生前窄范围预授权。她补充一条棘手实情：旧闸人工接管要用的联接销后来借给下游排水泵。能否拆、怎样装由专业队判定，**许砚必须解决的是把替代抽排装备和持证班组准时运到河谷**，否则一边开闸一边让另一片居民断排水。

2056年的原始现场核验记录来自林禾与另一名工人的纸本和机械准备痕迹，不可拿错误地下地图或中心模型成功摘要代替。她愿指认联接销所在地点，但不允许不合格人员因赶时间私拆正运行的泵。许砚能拿出的是承运承诺和真实报酬，不是机械安全保证。

本章钩子：洪水将到，唯一能合法到场的车次又被邵进盯上。
