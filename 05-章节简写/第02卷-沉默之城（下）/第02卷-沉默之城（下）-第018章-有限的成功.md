# 第02卷 沉默之城（下） 第018章-有限的成功

洪峰后多数居民获救，另一撤离通道重伤的救援工人最终不治，独立调查展开。许砚交出2049年的未签收药单、这次真实车次、补访委托和亲手误勾的L-17通知表；当面承认已发现空栏却没有追到接班人的回执，不把“车已派、通知已发”冒充“人已得救”。叶澄母亲受伤，叶澄拒绝一句“尽力了”，提出每户真实到达、具名替班和可以追责的最低要求；许砚将这些加入下一轮配送与应急交接协议。闸门因何卡滞、另一救援工人的具体死因仍由有资质者调查，不能把所有事故归咎于一份通知。唐序带真药和电力试点交换远程接口；许砚先让药师验货、司机落实下一棒，再进入复兴城谈有限可撤回的合作。

许砚准备进入复兴城市，不是因为学会开闸而被招募，而是别人看见他在混乱中仍能组织真实司机、药师、仓管和现场名单。他的过失没有被功劳覆盖；叶澄对真人到户与付费接班的要求，将在第五、第六卷成为能反过来约束主角的新规则。

本章钩子：旧世界的效率能救命，谁保证下一次有人真正接班？
