# 第02卷 沉默之城（下） 第016章-谁来签字

顾禾拿纸图追问L-17：“那户谁敲过门？”许砚查到签名只属于院内原住户，当众撤回“全院收到告警”的汇总，但第一车正载着重症老人离开险区，第二辆合法车辆承担急药转运。他把L-17二次补访托给临时协助员，只听到“我去叫人”，**没有指定接班人、没有追到门口的具名回执，也未把空栏放进最高级救援队列**；通讯随即断续。这是他第二次可纠正而没有闭环的决定。与此同时，黎照组织合法应急程序，水文员、泵站及专业水工只对具备条件的有限抽排和旧闸动作签署可撤回意见，夏芒核设备、不让许砚代签。

补访协助员确实表示愿去敲门，却没有收到清楚分派的交接责任，也没有把门牌和接收人回传。许砚本可以把这户标成紧急未完成、让应急席继续追车和追人，最后却止于一次口头托付；专业人员讨论闸门不应挤掉这场主角本职的失败。

本章钩子：救护车还在路上，L-17没人回话，旧闸试动作却卡住了。
