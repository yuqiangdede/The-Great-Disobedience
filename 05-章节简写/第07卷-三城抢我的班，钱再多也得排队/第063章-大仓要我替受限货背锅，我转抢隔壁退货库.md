# 第063章 大仓要我替受限货背锅，我转抢隔壁退货库

> V18独立简写｜第七卷｜2061年冬

第二城退件大仓把普通退货和一批承运资质不符的受限货混报成“一车价”，仓管让梁凯先拉走，出问题以后再补手续。邵进的报价更低，仓管故意当着梁凯的面打电话催他签。梁凯想保住大单，先把照片发给许砚。许砚只回一句：“普通件能做，不能做的别碰。把现有车位拿去找真的肯付钱的客户。”

他们不是出门碰运气。梁凯之前摸清了隔壁正规退货库的积压时段，知道那边正在临时比价，便带着本地合格合作方的车、司机、交接口和按范围赔付的报价单赶过去。邵进的车队也在场，标准退货件报价的确更便宜。梁凯不和他比整车最低价，而是挑出买方最头疼的错地址退件，现场让骑手按门店、楼栋和取件窗口重排接力，算出在约定时段里真实能处理的数量。

库方负责人先让两边跑一小段可核验交接：便宜且规则清楚的普通件交给邵进，容易二次扑空的一段付费夜班交给梁凯。梁凯接了有界时段和责任，不替原大仓收受限货，也没有把同一批货向两家重复收费。新买方当场确认试班与付款条件，原大仓那笔混货生意则真丢了；邵进也不是输光，只是没吃到这段难件。

梁凯刚要报喜，第三城群里跳出一个直播间链接：一名大主播正冲着郑涛吼，要求把昨天错过的揽收时间改成“早已收件”。
