# 第六卷·第118章《断线威胁》简写

状态：待作者审阅；正文未写。

联邦强硬派提出切断拒绝协定城市的跨区线路，病人组织警告这可能中断药厂和医院供电。黎照要求先评估影响范围、替代供电与断线顺序，拒绝签署未评估的执行单，随即被停职，系统档案权限冻结。她仍提交公开会议记录，并把命令来源交给独立审查组；家属代表共同核验她保存的预算副本，另有互不隶属的见证人分别留存副本和校验值。记录显示强硬派官员曾削减备用预算，但他们称那是财政取舍，与断线无关。黎照将原预算、删减理由和实际影响分开公开，不把先后关系当作动机证据。停职使她无法正式调档，审查组尚未确认证据链完整；病人组织要求公布各医院备用时长，强硬派只提供无法定位药厂风险的总量估计，断线仍被催促。

病人组织要求列出断线后各医院的备用时长，强硬派只给无法定位具体药厂风险的总量估算。黎照无法正式调档，只能依赖独立审查组核验来源；预算删减与断线计划是否有关仍是待查问题。

本章钩子：停职令要求黎照交出个人保存的预算副本，她必须决定由谁共同保管这份尚待核验的证据。
