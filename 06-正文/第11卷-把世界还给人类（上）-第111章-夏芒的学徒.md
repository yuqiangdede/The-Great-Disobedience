# 第11卷 把世界还给人类（上）

## 第111章 夏芒的学徒

清晨六点，东郊水利实训基地还没开暖气。叶澄搓了搓冻僵的手指，站到模拟操作台前。

机房里有两面旧配电屏、一座半人高的闸门模型。墙上刷着一行白字：

【各司其职，越权即险】。

叶澄的防护服大了一号，袖口卷了两折，安全帽还是借来的。

旁边的陈晓峰二十四岁，读过水利专科，已经取得水工操作资格，来这里继续学现场处置。他正给模型上的钢丝绳上油，听见叶澄进门，朝她点了点头。

夏芒把护目镜推到额头上，等两人站定，才打开模拟故障开关。

“啪！”

夏芒按下模拟故障按钮。

叶澄面前的指示灯闪起来。蜂鸣器急响，打印机吐出一张故障纸带：

`FAULT ALERT: NODE-K GATE #2 WATER LEVEL INCONSISTENCY (SENSOR: 43.40m, MANUAL: UNKNOWN)`

叶澄看到“水位异常”，伸手就去掀“闸门电动闭锁”旋钮上的红盖。

“啪！”

夏芒的木戒尺抽在她手背上。叶澄缩了手，皮肤上立刻浮起一道红印。

“啊！”叶澄捂住手，抬头看着夏芒。

“谁让你碰那个旋钮的？”夏芒把戒尺搁到一旁，“报错的是水位数据。你知道闸门现在开到哪儿吗？”

“夏工，水位报警了！”叶澄忍着疼，“我不是该先把错误操作停下来吗？”

“停错了怎么办？你有权暂停的是未经核验的调度指令，不是闸门本身。”

叶澄答不上来。夏芒指向陈晓峰：

“晓峰有操作资格，也得先去现场看闸门、水位和设备状态，不能隔着这张纸乱动。你只有协调权，更不能动。传感器出了错，不等于闸门必须关。万一水流正顶着闸门，关错了，下面的管道和人都可能遭殃。”

夏芒把一本翻旧了的操作手册推给她：

“晓峰在坝上跟师傅干过三年，听得出电机卡住时是什么动静。真遇上卡阻，还得由他们按现场规程处理。你昨天能把水送到居民手里，那是你的本事。可这台闸门不是水车。”

叶澄把手背藏到身后。夏芒看见了红印，声音仍然硬：

“昨天你把水车调对了。今天这一下要是真闸门，可能就调错了。你可以拦下未经核验的指令，找人复核；你不能替水工落闸。记住这条线。”

叶澄脸上发热。她想辩解，话到嘴边又咽了回去。

手背疼，她更难受的是自己差点真去拧那个旋钮。

昨天她刚在红星街区顶住了吵闹的人群，把一车水分给最急用的人。别人喊她“小叶姑娘”，可回到家，母亲连电话都不愿再接。

她本想靠这次培训证明自己能独立接班，一上来却犯了这样的错，还当着陈晓峰的面挨了一戒尺。

站在旁边的陈晓峰也有些尴尬，低声劝道：“夏工，小叶刚才也是着急……她毕竟才第一天参加正规培训……”

“正因为是第一天，才要拦住。”夏芒看着叶澄，“出了事，‘我想救人’这四个字顶不了用。先弄明白自己能按哪个键。”

夏芒把故障纸带放在叶澄眼前：

“重来。你现在是有街区有限派车权的见习协调员，不是闸门操作员。报错之后，你先做什么？”

叶澄吸了口气，盯着纸带回答：

“先暂停这条未经核验的自动指令下传，不能去碰现场闸门。”

“再打电话找现场值班的人，核姓名、到岗情况和水尺读数。”

“数据对不上，就把时间、谁报的数、差多少记下来，叫有资格的人到现场复核。我负责找人和传话，不替他们操作。”

陈晓峰点了点头，又看了一眼叶澄的手背。

夏芒也看见了那道红印，没再让她背第二遍。

“动作做一遍。”夏芒的声音放平缓了一些。

叶澄走到通信台前，先看清按钮旁的标签。

她按下【暂停命令下传】，屏幕上的自动下传标志熄灭了。

模拟系统停在黄色待核状态，闸门模型没有动作。

她拿起模拟电话：“K号闸主控室吗？我是叶澄。请报值班员姓名和现场水尺读数。”听筒里传来陈晓峰事先录好的应答，她逐项写下。

她对照模拟传感器的读数，核了一遍纸上的时间，把记录交给陈晓峰：

“两边水位差零点八米。请你带人去现场核，先别按远端读数动闸门。”

陈晓峰接过记录：“我先确认模拟现场的设备状态，再决定怎么处置。”

夏芒检查她的记录，指着时间栏：“这次对了。但电话里报数的人是谁，要写全。”叶澄补上名字。

夏芒摘下护目镜，摸了摸自己额角的汗。

夏芒拿出一盒清凉油，递给叶澄，没有替她抹。

叶澄没接。她把手背朝夏芒亮了亮，红印还在。

“疼吗？”夏芒低声问。

“疼。”叶澄咬着牙，眼眶微红，但没有低头。

“刚才动手，是我不对。”夏芒把清凉油放在桌上，“我可以拦你，也该用别的办法。你要是想投诉，照规矩报。还有件事，你心里是不是一直觉得，许砚安排你来培训，是因为对你家有愧？”

叶澄朝桌上那盒清凉油看了一眼。

叶澄没回答。她想起昨天挂断的那通电话，喉咙发紧。

来基地的路上，有街坊在背后说她靠许砚的关系才有这份工作。她听见了，没回头。

她想把事办好，尤其想让母亲知道：昨天没给家里先送水，不是为了讨好谁。

“许砚对你家有亏欠，这事谁也抹不掉。”夏芒说，“但你昨天真的把车调出去了，司机真出车、居民真领到水。你拿到的是有限派车权，不是随便进机房动设备的通行证。”

叶澄问：“那我怎么知道自己不是靠他的面子进来的？”

“昨天广场上，系统说水车送达，车却在车库。你去找司机，带着备用车把水送到人手里。那些领水的人签过名，这才算数。”

夏芒把操作手册翻到事故处置那页，推到她面前：

“你能做好的，是把屏幕上的‘完成’查到真人手里。培训也是让你学会什么时候该喊停、该找谁接手。这份活需要你，也需要晓峰这样的人。”

夏芒把笔递还给叶澄：

“你现在还是见习，别急着证明自己什么都能做。先把每一次报错记准，找到能接班的人。等培训考完，再谈下一步的资格。”

叶澄望着桌上那盒没打开的清凉油，眼泪掉了一滴。她赶紧拿袖口擦掉。

“我知道了。”她说，“我不动闸门。有人报错，我得先问清楚谁在现场。”

“这项过了。手背的事，下课我会登记。”夏芒拿起下一张模拟题。

墙角的电传机突然响了。夏芒放下模拟题，转身去看纸带。

“哒哒哒！哒哒哒哒！！”

纸带一行接一行吐出来，最上方印着红色警示：

`RED TELEGRAM: UPPER REACHES "LINJIANG AUTONOMOUS GRID" REJECTS FULL DATA SHARING`

`ALERT: S-STATION UNATTENDED HYDROLOGICAL NODE DETECTED TIME-STAMP DISCREPANCY!`

`CURRENT STATUS: S-STATION OPERATING IN UNATTENDED AUTOMATIC MODE -> NO QUALIFIED CREW ON-SITE!`

夏芒撕下纸带。叶澄跟过去，先看见了“S站”和“采样时间异常”几个字。

夏芒翻开本地夜班台账，核对下游备用站点的值班名单。

临江城暂不共享上游全量数据。S水尺站的一条采样时间与中心记录对不上，系统已拦下有争议的自动摘要。原因还没查明。

下游南山二号备用站的排班表仍显示“两名水工在岗”。夏芒拨了站里的有线电话，响了很久没人接。

“这两个人真在吗？”叶澄问。夏芒没有回答，把旧联系方式递给了她。

雨已经连下两天。河里水位还在涨，但洪峰究竟什么时候到，得等现场水文人员核实。

叶澄看了一眼自己刚写完的模拟记录，拿起电话。

“先找值班的人。”她说，“如果真没人，得赶紧找谁能顶上。”
