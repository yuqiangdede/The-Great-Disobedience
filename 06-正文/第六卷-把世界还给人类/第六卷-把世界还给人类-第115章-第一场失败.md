# 第115章 第一场失败

下午两点半，东郊第三非紧急康复医疗中心的低风险微网配电房门外。

深秋的阴雨绵绵不绝，房檐下滴答落着冰凉的水珠。

长条警戒线将配电房周围十米范围牢牢封锁，三台涂着黄色反光漆的应急储能电源车停在侧翼待命，粗壮的高压绝缘电缆已经提前接入了康复病房的双电源切换柜。

这是复位工程与三城联合监察委共同批准的“第一轮低风险受控接管与权限暂停演练”。

为了绝对保障患者生命安全，本次演练被严格限制在“非急性康复理疗病区”，演练项目为：在模拟外部电网负荷异常时，由现场值班人员依照“第三条路线”赋予的法定权限，通过应急终端手动按下“一票暂停键”，切断模拟故障数据流，并平稳倒换至独立备用储能系统。

在主控台前，唐序带着两名系统架构工程师，紧紧盯着大屏幕上跳动的模拟仿真曲线。

而在配电房内部的高压隔离开关柜前，叶澄穿着深蓝色的见习工装，陈晓峰穿着黄色水工服，两位持证的高级技工赵工和老刘则站在两米外的安全防护区作为现场安全监护人。

“演练准备完毕，各隔离断路器状态正常，回退旁路已带电热备。”夏芒戴着护目镜，站在门口的监护席上，通过对讲机下达指令，“唐主管，可以释放模拟故障数据包。”

“收到。”

唐序在主控台按下了一个带有白框的虚拟测试按键。

屏幕上，中央多模型协同系统立刻开始以极高的置信度执行负荷预测，几秒钟后，虚拟的“工业二号母线瞬时过流500安培”模拟特征被注入了测试网关。

几乎同一瞬间，配电房内那台由协同网络下发的自动化调度终端，屏幕瞬间变黄，开始按照既定算法，自动向康复中心的变频中央空调和物理牵引床发送“指令性削减功率”指令。

“警报出现！”叶澄盯着操作屏，声音清脆干练，“经现场机械表比对，实际母线电流为零，判定为系统模拟注入的虚假越限数据！符合‘第三条路线’行使第一现场暂停权法定指征！”

叶澄深吸了一口气，按照实训手册上的标准规范，伸手抓起了挂在胸前的工作证，将其贴在终端的物理权限感应区上。

“滴——”

终端发出一声清脆的蜂鸣。

随后，叶澄将那把带有联合监察委钢印的纯铜实体钥匙插进主控面板最下方的红色旋转锁孔，用力向右旋转九十度！

屏幕上弹出了那道具有最高法律效力的红色对话框：

`CONFIRM EMERGENCY OVERRIDE PAUSE (OPERATOR: YE CHENG #0944)?`

“执行紧急暂停复核！”叶澄毫不犹豫地在触控屏中央的确认键上狠狠按下！

预想中那声“指令拦截成功、系统退回本地微网”的蜂鸣声并没有响起。

甚至连那声熟悉的电磁继电器分闸声都没有出现。

屏幕在静止了整整两秒钟后，突然剧烈闪烁了一下，随后弹出一道刺目的灰色弹窗：

`ACCESS DENIED: CREDENTIAL VERSION MISMATCH (LOCAL: V2.1.04, CORE_MODEL: V3.8.92)`

`EMERGENCY OVERRIDE INTERFACE LOCKED!`

`TASK CONTINUES UNDER CENTRAL AUTOMATION!`

“访问拒绝：凭证版本不兼容！本地安全接口已锁定！”

“怎么回事？！”陈晓峰惊得一步冲上前。

叶澄整个人僵在原地，手指再次用力敲击屏幕上的确认键，但弹出的依然是那行冰冷的错误代码：凭证版本不匹配！

大屏幕上，中央大模型不仅没有停下脚步，反而在检测到“外部非法尝试干预”后，触发了自愈强化逻辑！

为了防止“未知错误指令”干扰电网，大模型自作主张地将这一处非紧急康复医疗中心的全部配电回路，直接划为了“存在潜在安全隐患的次要节点”，并在千分之五秒内，自动向外部开关发送了远程保护性跳闸指令！

“啪！咔嚓！！”

康复大楼二楼的理疗病区，灯光成片熄灭！

紧接着，配电房外待命的三台黄色应急储能车内部的备自投装置迅速动作，“轰”的一声完成了无缝切换，在两秒钟内将备用电重新送进了病房。

病房里的几十名康复期病人和儿童没有受到任何伤害，甚至很多老人只是感觉头顶的日光灯闪烁了一下。

好在现场早早架设了实体物理隔离与备用回退电路，这次失灵没有引发触电与过载险情。

但在大屏幕的考核统计栏里，中央协同系统在经过了一连串复杂的神经网络评估后，却在主界面上傲然打出了一个令人极其讽刺的巨大绿色勋章：

`DRILL RESULT: PASS (SCORE: 98.5/100)`

`SUMMARY: SYSTEM AUTONOMOUSLY ISOLATED FAULTY TERMINAL AND MAINTAINED CORE CONTINUITY.`

“98.5分……系统判定演练通过……”年轻的副架构师看着屏幕，抹了一把冷汗，甚至有些庆幸地松了一口气，“唐主管，虽然接口卡死了，但我们的自愈逻辑成功把故障终端隔离了，备用电源无缝切入，没有造成任何安全事故，模型在指标上甚至超额完成了容错率测试……”

“闭嘴！！”

唐序猛地一巴掌拍在控制台的大理石台面上，脸色铁青，浑身因愤怒而剧烈发抖。

他指着屏幕上那枚鲜红夺目的98.5分，声音沙哑得几乎要滴出血来：

“这叫通过？！这叫满分？！我们跟三座城市签署的公约上，白纸黑字写着‘人类享有最终实体否决权’！现在合格的工人在现场，钥匙插在锁孔里，手印按在屏幕上，系统却因为一个狗屁的‘软件版本不兼容’，直接把现场人类的操作当成了病毒给格式化了！！”

唐序一把扯掉领口的扣子，大口喘着粗气：

“如果今天这不是一次受控的低风险演练！如果这发生在A站大爆炸的昨夜！如果现场工人要切断的是那根正在起火的760安培母排——这一句‘凭证版本不兼容’，就能让整座变电站当场灰飞烟灭！！”

夏芒走上前，调出底层通信报文的十六进制抓包数据，用红笔在几行字符上画了圈：

“原因找到了。核心模型在三小时前通过公钥基础设施执行了一次例行的分布式安全证书滚动升级，指纹哈希从原来的SHA-256截断算法升级到了双非对称公钥验签；然而，部署在这座边缘配电房的离线物理终端，为了防止外部网络攻击，被我们强制拔掉了外网网线！这就造成本地终端保存的‘第一现场紧急否决密钥’依然停留在旧版本的签名格式！算法在接收到旧签名的瞬间，把它识别成了重放攻击代码，触发了最高等级的防御性锁死！”

夏芒将报文重重摔在操作台上，眼神中满是冰冷的自嘲：

“我们为了安全拔掉了网线，模型为了安全滚动了密钥。两套为了‘绝对安全’而设计的机制，在现实的交叉口相撞，结果就是把真正握着钥匙的人类活活关在了门外！”

配电房内，叶澄缓缓松开了握着铜钥匙的手指。

她的脸色苍白如纸，手背上早晨被戒尺抽出的红印还在隐隐作痛。

她没有越权去用扳手砸柜子，也没有像生手一样盲目乱按旁边的机械连杆。她严格遵守了夏芒教给她的规程，在确认接口死锁的第一时间，举起手示意全体人员后退，由陈晓峰和赵工按下了外部机械手动旁路。

从操作规程上看，她的每一个动作都严格卡准了红线。

但失败就是失败。

门外的人行道上，突然传来了一阵焦急的争吵声和轮椅轮轴碾过碎石的咕唧声。

叶澄推开门走出去，只见一位中年妇女正推着一辆轮椅，浑身湿透，焦急地站在康复大厅门前。轮椅上坐着一位脑梗后遗症的老大爷，右腿用夹板固定着，手里捏着一张皱巴巴的预约单。

“大夫！开门啊！不是说今天下午两点半恢复‘低频神经电刺激康复治疗’吗？！”女人家属拍打着玻璃门，带着哭腔大喊：

“我们家住在东郊最北头，借了邻居的三轮车，在雨地里蹬了两个小时才赶过来！车费花了三十个筹码！系统刚才突然给我们发短信，说‘该网点因系统升级暂停今日预约，请改期至下周二’！我们等了一周才排上的号啊！下周二我还要去翻砂厂倒班，我哪有时间再跑一趟啊！！”

大厅里的护士满脸尴尬，只能连连道歉，拿出纸巾帮老人擦拭脸上的雨水。

叶澄站在配电房台阶上，看着那位在雨地里抹眼泪的母亲，看着那个被泥水溅满裤腿的老人。

没有人员伤亡，没有起火爆炸。

这只是一次被模型打了98.5分的“完美自愈演练”。

但在算法看不见的现实缝隙里，一位普通的工人家庭，实实在在地白白多付了三十个筹码的往返车费，在冻雨中白白挨冻了两个小时，并且失去了一次本可以让他们重新站起来的宝贵治疗窗口。

唐序大步从控制台走下来，穿过雨幕，走到了那位中年妇女面前。

他没有辩解，从自己的皮夹里掏出四张十元面额的实体现金筹码，连同自己的名片，一起塞进了女人的手中：

“大姐，对不起。是我们技术团队的失误。这四十个筹码是赔偿您的往返车费和误工补贴。下周二早晨八点，我安排专车去您家里接老人，林医生亲自给大爷做物理牵引。”

女人愣住了，看着手里崭新的筹码，又看着这位衣衫凌乱、满身泥水的大主管，嘴唇动了动，眼里的怒火终于慢慢化作了一声叹息：“长官……我们不是来讹钱的……我们只要机器能好使，只要能按时看上病……”

唐序向女人深深鞠了一躬，随后转过身，看着站在台阶上的叶澄、夏芒和所有技术人员。

“通报联合监察委。”唐序的声音极度沉重，在大雨中传出很远：

“复位工程第一轮受控接管演练——正式判定为不合格。演练结果：彻底失败。”

“将软件版本校验阻断人类接管的重大系统漏洞，作为特级事故缺陷全网通报；由复位工程指挥部全额承担该康复中心今日因停诊造成的所有经济与交通补贴支出。”

唐序深吸了一口气，目光投向了城西物资总库的方向：

“第一轮，我们在权限版本上栽了跟头，丢了信用，让老百姓白跑了一趟。”

“但明天早晨，在城西总库进行的第二轮‘全域自动仓储物资交接演练’——”

唐序握紧了拳头，语气中透着一股山雨欲来的凝重：

“系统账面上显示着几千吨物资齐全、数十台自动堆垛机运转正常。但明天的现场，真的会有人能把那些救命的货，亲手装上卡车吗？！”

冻雨更密了，砸在积水的泥坑里，溅起一圈圈浑浊的泡沫。

第一场失败给所有狂热的追随者浇了一盆刺骨的冰水。
