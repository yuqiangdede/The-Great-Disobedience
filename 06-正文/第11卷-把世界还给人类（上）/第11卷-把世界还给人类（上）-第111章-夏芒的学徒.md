# 第11卷 把世界还给人类（上）

清晨六点整，东郊水利与电力实训基地的模拟机房里，泛着一层刺骨的湿冷。

大厅中央摆着两台退役的重型铸铁配电屏和一座半人高的缩比水库闸门模拟联动台。墙上用白油漆刷着八个巨大的标语：

【各司其职，越权即险】。

叶澄站在配电屏前，身上套着一件略显肥大的纯棉防电弧阻燃服，头上戴着白色的安全帽。

在她身旁，站着另一位年轻的学徒工陈晓峰。陈晓峰今年二十四岁，是水利专科学校毕业的正规持证水工学员，腰间挂着重型活络扳手、机械测厚仪和铜游标卡尺，手里正拿着一把黄油枪在给闸门模拟钢丝绳抹防锈油脂。

夏芒穿着那身深灰色的工装，护目镜推在额头上，两只手插在口袋里，神色严肃地站在操作台前。

“啪！”

夏芒伸手在模拟故障控制台上狠狠按下一个黄色按钮。

叶澄面前的红绿指示灯瞬间乱闪，蜂鸣器发出了刺耳的急促短鸣，一台老式热敏打印机开始疯狂吐出一条带有乱码的异常警报纸带：

`FAULT ALERT: NODE-K GATE #2 FLOW INCONSISTENCY (SENSOR: 140m³/s, MANUAL: UNKNOWN)`

叶澄神经一紧，双手本能地伸向了操作台上那枚带有红漆保护罩的“闸门电动闭锁”旋钮，作势就要拧下去。

“啪！”

一把硬质木戒尺狠狠抽在叶澄的手背上，力道大得让她的手背瞬间泛起了一道通红的指印。

“啊！”叶澄痛得缩回手，捂着手背，有些委屈和不解地看着夏芒。

“你在干什么？！”夏芒的声音冷得像结了冰的铁轨，“谁给你的权力去碰闸门闭锁旋钮？！”

“夏工！警报响了！传感器流量异常！”叶澄咬着嘴唇辩解，“我是应急协调员，我不该立刻停下错误的操作吗？！”

“你是应急协调员，不是水利高级操作员！”

夏芒将戒尺重重拍在操作台上，指着旁边的陈晓峰：

“去拧这个旋钮的人，必须是经过国家水利机械资质认证、持有一级承压水工操作证的陈晓峰！你叶澄的职责是看纸带、抓电话、核时戳、找活人！你连水力学空蚀临界压力和闸门反向水锤系数都没学过，你这一手拧下去，如果上游处于水力瞬变峰值，闭锁阀门会在两秒内击穿地下涵管！”

夏芒将那本厚重的《水利工程承压设备安全规范》重重拍在叶澄胸口：

“晓峰为了考下这本三级水工执照，在深山大坝的机坑里当了三年学徒，拆装过两百台电动推杆和双向伺服油缸！他知道闸门落到三分之一处如果遇到漂浮原木卡阻，电机会发出什么样的闷响！他知道在无动力状态下如何使用手动绞盘平衡动水闭门力！这些带血的工程经验，任何算法和大模型都替不了，你一个刚拿派车单的见习调度员更替不了！”

夏芒逼近叶澄，眼神严厉得没有丝毫温度：

“你以为你昨晚成功调了一车水，你就是全知全能的救世主了吗？！你以为会开派车单，就能替电工拉闸、替水工落闸、替医生开方了吗？！如果调度员凭着一腔热血就能跨界乱按开关，那要专业工程师干什么？！那要这间实训基地干什么？！”

叶澄的脸色由红转白，双手死死攥紧衣角，头盔下的碎发被汗水打湿。

她感到胸口一阵窒息般的委屈。

在昨晚以前，她是红星街区人人敬重的“小叶姑娘”；在昨晚，她独自一人扛住了上千名愤怒职工的围攻，把两吨救命水分毫不差地发到了危重病人家里。

而在今天，在这个冰冷严苛的实训室里，夏芒却像对待一个毫无常识的笨蛋一样，当着同龄学徒的面，狠狠抽打她的手背，把她身上所有属于志愿者的骄傲砸得粉碎。

站在旁边的陈晓峰也有些尴尬，低声劝道：“夏工，小叶刚才也是着急……她毕竟才第一天参加正规培训……”

“第一天就更要把规矩刻进骨头里！”夏芒没有丝毫缓和，“在现代复杂工程里，好心往往是造成灾难的罪魁祸首！十二年前的大静默，最初也是由一群自以为全知全能的模型架构师，试图用一套通用的算法逻辑去接管所有专业领域的决策！结果呢？！一个跨界越权，整座大陆瘫痪了整整十二年！”

夏芒转过身，指着打印机吐出的那张纸带，看着叶澄：

“重来！叶澄，我问你，作为持证的基层应急协调员，当你的终端收到这道‘数据不符’的黄色警报时，你的标准化动作第一步是什么？第二步是什么？第三步是什么？背！！”

叶澄深吸了一口气，强忍着眼眶里的泪水，昂起头，用颤抖却坚决的声音大声背诵：

“第一步：立即启动独立物理隔离，按下‘异常命令下传暂停键’，切断未经核验的数据流向下级执行机构自动漫延！”

“第二步：抓起有线调度电话，直接连通发生异常的现场控制室，核验当值值班人员的工号、姓名、活人到岗状态及实体仪表读数，绝不采信未经二次交叉核验的云端摘要！”

“第三步：一旦确认数据冲突，在实体调度日志上如实记录时戳、报数人及冲突量，即刻在公共频段以实体红头调令呼叫该专业持证人员赶赴现场接管处置！严禁由调度员个人代行现场高危物理操作！背诵完毕！！”

女孩清脆有力的声音在空旷的实训室里回荡。

夏芒看着她挺拔得像一根标枪的身躯，看着她手背上那道刺目的红印，眼神深处的严厉终于缓缓融化了一角。

“动作做一遍。”夏芒的声音放平缓了一些。

叶澄没有丝毫犹豫。

她一步跨到通信操作台前，左手稳准狠地拍下了黄色的【暂停命令下传】实体物理拍钮！

“咔嗒！”联动回路断开，红灯锁定为黄色待命。

紧接着，她右手抓起摇把电话，迅速摇动三圈，将听筒死死贴在耳边：“呼叫K号受控闸主控室！我是东郊见习协调员叶澄！请报出当班值班员姓名及现场实际水位尺读数！……收到，已记录！”

她一把抓起钢笔，核准时间，撕下盖有红章的调令，两手递到陈晓峰面前：

“陈工！K号闸现场水尺与传感器存在零点八米偏差！请即刻携带机械测高仪与手动操作手柄，赶赴现场复核接管！”

陈晓峰接过调令，立正敬礼：“陈晓峰收到，即刻出发！”

整个过程，整整齐齐，三十八秒完成，挑不出哪怕一丝一毫的瑕疵。

夏芒终于放下了手里的木戒尺，摘下了满是汗水的护目镜。

她从口袋里掏出一盒清凉油，拧开盖子，用手指挖了一点，走到叶澄面前，轻轻抹在女孩红肿的手背上。

清凉的薄荷脑刺激着滚烫的皮肤，带来一阵火辣辣的疼痛与舒缓。

“疼吗？”夏芒低声问。

“疼。”叶澄咬着牙，眼眶微红，但没有低头。

“疼就对了。”夏芒拉过一把折叠椅坐下，示意两个学徒也坐下，“叶澄，我知道你在想什么。你觉得许砚是因为愧疚，是因为十二年前老河谷欠你母亲一条命，今天才特批把你塞进这个正式编制的培训班里，对不对？”

叶澄的身体微微僵硬了一下，没有吭声。

这正是扎在她心头最深的一根倒刺。

今早走在路上，几个老街坊在她背后指指戳戳，说她“到底是许大主管的关系户”、“当年挨了一场洪水，换来闺女今天吃公家饭”。

这些闲言碎语像刀子一样割在她的脊梁骨上，让她比任何人都急于证明自己，急于向所有人展示她不需要靠任何人的施舍就能拯救世界。

“许砚确实对你母亲有愧疚。”夏芒点燃了一支薄荷烟，吐出一口淡淡的青烟，“但许砚是一个把规矩看得比命还重的轴汉子。如果今天你叶澄只是个靠着眼泪要特权的关系户，就算他跪下来给你家磕头赔罪，他也绝不会把那把车钥匙和准考证交到你手里。”

夏芒看着叶澄清澈的双眼：

“昨晚在风雨里，全城几十个官员、几百个网格员，都在围着电脑看那个虚假的完成率。只有你一个人，拿着纸笔，挨家挨户敲开棚屋的门，把五十三户活生生的人给找了出来。”

夏芒的声音很沉，带着一种经历过无数灾难后的厚重：

“机器擅长计算十亿个变量，但机器看不见黑暗角落里快要冻死的活人。把活人找出来，并且敢于为了活人去拦住机器的错误——这就是你被选进这个班的唯一理由。”

夏芒站起身，拍了拍叶澄单薄却坚韧的肩膀：

“别管旁人怎么嚼舌头。你的执照是用命挣来的硬本事，不是凭人情换来的。从今天起，忘掉你是个志愿者，忘掉你是个受灾者的女儿。坐在调度席上，你就是这道防线上唯一的守门人。”

叶澄低着头，看着手背上那抹清凉油泛起的油光，鼻尖猛地一酸，两滴滚烫的泪水啪嗒一声砸在工装夹克的裤腿上。

她深深吸了一口气，抬起头，用力擦干了眼泪：“夏工，我明白了。我不碰闸门，我把闸门前面的人守住。”

“好，有这个觉悟，今天的实操就算及格了。”夏芒掐灭了烟头，正准备布置下一项科目。

还没等她把话说完，实训室墙角那台用于接收跨区报文的旧式电传打字机，冷不防爆出了急促密集的金属撞针声！

“哒哒哒！哒哒哒哒！！”

厚重的加宽穿孔纸带疯狂吐出，伴随着刺耳的红色最高警报蜂鸣：

`RED TELEGRAM: UPPER REACHES "LINJIANG AUTONOMOUS GRID" REJECTS FULL DATA SHARING`

`ALERT: S-STATION UNATTENDED HYDROLOGICAL NODE DETECTED TIME-STAMP DISCREPANCY!`

`CURRENT STATUS: S-STATION OPERATING IN UNATTENDED AUTOMATIC MODE -> NO QUALIFIED CREW ON-SITE!`

夏芒快步冲到打字机前，一把扯下纸带，脸色瞬间铁青。

纸带上清清楚楚地显示着：

上游那个高度自动化、拒绝加入三城协议的“临江城”，其边境关键的S水尺站，因为系统内部模型版本冲突，触发了局部异议拦截；

但是，在这座号称全自动、零人工的无人值守站点里，旧网络上明明挂着“两名高级水工在岗”的漂亮排班表——

而在真实的物理现场，那座锁在深山峭壁上的观测站内，此刻却空无一人！

深秋的暴雨已经连续下了两天两夜，河谷上游的洪峰正在以每小时三十公里的速度向下游压来。

无人站点发出了虚假在岗的假报告，真正的物理闸室里冷如冰窖。

在暴雨狂澜的夜幕降临前，真正能赶到现场、能握住那把冰冷测绳的合格人类，究竟在哪里？！
