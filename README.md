## 一句话定位

35岁的外卖骑手许砚因差评被扣钱、明早面临收回租车，靠送餐跑快递练出的熟路和真人交接本事挣到独立首款，05章清车租，09章兄弟分钱，后续从自营配送合作站扩到三站、三城真实商户夜班；第129章同一个给过他差评的人带正常预款排队，第130章他第一次真能休息。

**正文重点是外卖、普通快递、末端取送、商超夜配、退货集配、骑手工资、站点经营、竞争与逆袭**；医疗、供水、电网、工业事故仅保留已经确认的因果与后果，不准重新抢走主角商业故事。
