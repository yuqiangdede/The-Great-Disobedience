# 《大模型不听话》

大众向灾难悬疑＋废土冒险＋技术复兴长篇小说。主线不是“AI变笨”，而是高影响任务的执行授权链在2049年开始失效，社会在十二年后仍为失去真实物流、供给与现场接管能力付出代价。2061年，许砚以急件配送与旧网接口核验为起点，逐步追回人能看见、能反对、能接班的能力。
