# 《大模型不听话》

长篇科幻小说项目，类型为**大众向强剧情灾难悬疑＋废土冒险＋技术复兴＋群像成长**。目标是让普通读者不需要学习大模型术语，也能直接跟随人物的救人、查证、争资源与承担后果。2049年模型没有突然变笨，而是高影响任务的执行授权首先失效，长期依赖模型自动协调的社会失去自行组织的能力；2061年许砚从社区配送与旧网接口核验进入更大的调查。
