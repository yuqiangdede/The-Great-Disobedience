# 《因果静默》

长篇科幻小说项目。当前状态：已保存作者第一版设计并初始化项目；六卷为初步故事框架，章纲、简写和正文尚未创作。

- 00-原始资料：作者提供的完整设计原文。
- 01-世界观：时代、因果闭合、势力和未解科学谜团。
- 02-人物：主要人物与关系，后续可建立独立小传。
- 03-故事规划：核心悬疑与六卷总纲初版。
- 04-写作规则：故事原则和项目规则。
- 05-章节简写、06-正文：为后续创作预留。
- 07-事实与时间线：只记录经正文确认的事实。
- novel.project.json：写作工作参数；字数为暂用默认值。

原设计规划六卷共130章，约50—65万字。下一步可细化第一卷卷纲，再制定章纲与简写；正文须在相应章节概要和简写获作者批准后开始。

新增设计：大模型训练、推理、数据集、幻觉、过拟合、微调、蒸馏、剪枝与对齐，见 `01-世界观/大模型基础与文明设定.md` 和 `03-故事规划/六卷剧情融入-大模型基础.md`。

六卷130章规划初稿见 03-故事规划/全书卷纲与连续性索引.md，分卷详见 03-故事规划/分卷章纲。

作者指定的俏皮活泼、微喜剧风格及人物声口见 `04-写作规则/文风与微喜剧基准.md`。
