# 《因果静默》参考作品

作者指定三部作品供创作参考。这里保存的是依据出版方、馆藏与书评资料整理的原创摘要及本项目写作笔记，不是小说原文，也不是逐页研读报告。资料可能包含基础设定和开篇情节；如果准备无剧透阅读，可先看书目链接。

- 01《软件体的生命周期》：把 AI 问题放进日常劳动、维护和责任。
- 02《挽救计划》：科学问题、悬疑推进与幽默的组合。
- 03《All Systems Red》：轻快的角色声口与危险任务。
- 04 三部作品如何用于本项目：按人物、卷次和具体场景落实。
