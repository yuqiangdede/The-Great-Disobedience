# V6 番茄书名、简介、封面文案与外卖骑手读者定位

> 2026-11-11｜书名是**建议发布候选**，不是用户最终确认或番茄后台已通过；内部仓名与novel.project.json仍为《大模型不听话》。V6主纲和130章卡是当前执行依据。

## 1. 第一推荐书名

# 《跑外卖的我，靠救命单翻身当老板》

**为什么选它**：第一眼看见“跑外卖的我”，骑手群体容易代入；“救命单”带真实危险与特殊机会；“翻身当老板”把小说承诺明确写在封面，而不是只卖AI故障悬疑。

**可能的缺点**：文字比《大模型不听话》更直白，对偏硬科幻读者吸引力较弱；书名是否达到番茄实际字符要求、是否重名仍须平台后台核对。故事中主角需从骑手做成**合法、有净利润的配送企业老板**，否则封面涉嫌夸大承诺。

## 2. 对比书名（均待平台查重）

| 书名 | 人群与卖点 | 局限 |
|---|---|---|
| **《跑外卖的我，靠救命单翻身当老板》** | 骑手代入+救人+赚钱+地位逆转，主推 | 偏直白；需在正文兑现商业成功 |
| 《外卖超时那天，我接下了救命单》 | 第一章矛盾强，封面好画 | 财富逆袭要靠简介补足 |
| 《送外卖的我，让甲方排队求接单》 | 对被催单与不被尊重者的强反差爽点 | “排队”不可写成全城无理由跪求 |
| 《从外卖骑手到多城配送老板》 | 事业升级直接明确 | 悬疑感弱，近商业纪实标题 |
| 《AI说送到了，我这个骑手却不信》 | 保留AI差异设定、第一章容易切入 | “人生赢家”结果不明显 |
| 《大模型不听话》 | 短、内部项目有识别度 | 不点出外卖、金钱和主角逆袭 |

**注意**：书名不得误导为系统发钱、获得签到外挂、全球AI变傻或单骑手能承担所有医疗/工程运输。标题允许商业化口吻，但情节必须真兑现。

## 3. 番茄风格简介：主推版

> 2061年，许砚还是个送外卖的。
>
> 电动车是租的，电池按天算钱，晚高峰刚被顾客投诉，他连热饭都没顾上吃。
>
> 可那天，医院的AI系统突然显示：**救命药已送达。**
>
> 护士急得发火，病人还在等药，运药车却压根没出仓。
>
> 那些坐办公室的人翻了半天报告，只有许砚知道——这条路上哪个门禁不认车、哪个库门晚上有人、最后一棒该找谁签。
>
> 他帮人把药真正送到，只挣到第一笔不起眼的核查费。
>
> 后来，厂长笑他只是送外卖的；大老板拿合同压他；三座城抢车抢人，恨不得让骑手免费替他们卖命。
>
> 许砚索性把那些肯干活、敢说没送到的骑手组织起来，自己接单，自己谈价，工资按时给。
>
> 从一辆欠租的电动车，到三座配送站，再到多城长期合同——
>
> **以前老板催他送快一点，后来老板们带着钱求他接单。**
>
> 等他终于有了自己的房子、公司和喜欢的人，城里又闹起一场大灾。
>
> 这一次，许砚连车钥匙都没拿。
>
> 因为真正让他赢的，是那群没有他也能把东西送到的人。

## 4. 更短的封面简介（适合120—180字选用）

送外卖的许砚，欠着电动车租金，晚高峰被投诉，连顿热饭都吃不安稳。可医院系统写“救命药已送达”的那天，他发现货车根本没出仓。别人只看屏幕，他认得每个库门、每位接货人。从第一笔核路费，到医院长期单，再到自己的配送站和多城公司，昔日看不起他的老板终于带合同上门求他出车。这个世界最缺的不是会算路线的AI，而是**有人真把东西送到、有人真给骑手发钱**。

## 5. 第一章前1500字必须具备的7个镜头

1. **送餐焦虑**：医院旁边的饭馆或骑手休息点，许砚因商家出餐/门禁等可理解原因被投诉；误会须具备可申诉渠道，**不直接套用“平台一定无理扣超时罚款”**。
2. **钱的紧迫感**：手机出现电动车租金/换电费用/合租房付款提醒；不报无依据的极端收入数字。
3. **身份羞辱**：穿着湿骑手服站在医院后门，管理者说“送外卖的别来添乱”，对手不是全体专家降智。
4. **AI反差**：医院屏幕“已送达”，护士空手，药还没出库；让读者一眼看懂。
5. **骑手专长**：许砚知道可走的实际路、晚班出入口、可能在岗的真人，能调动合规承运接驳，不越权搬运限制药品。
6. **可见胜利**：病人实际获医护核验的药；主角并不马上富有，反而有一单普通配送赔了时间。
7. **章尾悬念**：小费或服务费有支付主体、车租仍在，2049旧纸单上“已送达”也曾掩盖一个空白接收栏。

## 6. 第一人称职业爽点的最低频率

- 001—010至少出现五个来自骑手真实日常的摩擦：等餐、门禁、电梯、合租房与手机账单、换电或雨衣、同行群、商户沟通。
- 011—050骑手群不是召之即来的义工：每次必须明确谁有时间、谁有资格、谁为出车付钱、休息权是否被尊重。
- 051—071主角不会自己骑电动车跨城送特种药；跨城医疗只能用合规承运、医护接诊，许砚以熟悉交付链赚组织费。
- 072—106主角能为员工改善生活时，必须同时有公司亏损、逾期回款、税费、保险及真实资金压力；“逆袭”要敢写对赌/垫资的代价，但不能宣扬冒险越权。
- 107—130读者应该看见老板坐下来吃饭、敢拒不合理低价单、伴侣有独立事业、曾经跑单的兄弟拿到足额工资、团队敢当面纠正老板；这是人格与财富共同翻身。

- 001—005先因她饭馆出餐慢/许砚配送晚产生冲突，双方在实际账本上看到对方难处。
