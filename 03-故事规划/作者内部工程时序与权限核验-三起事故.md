# 《大模型不听话》三起事故的作者内部时序与权限核验

> **状态：2026-11-02现行规划约束；是小说后台因果卡，不是经过设计院、水文、电力或压力容器专家核定的工程计算书。**
>
> 目的：读者只要看见“人为什么赶不上、哪台设备先出问题、是谁有权叫停、救了谁、谁因此付代价”，就能读懂剧情；作者后台必须能把时序讲通。**任何未确定的参数不可在正文中冒充已核定的实际设计值**。
>
> 权威顺序：最新版全书主纲和六卷章纲为剧情依据；本卡给其工程和授权细节设必要条件，若发现冲突，返回主纲/章纲修订。涉及2056旧案时，2039—2061绝对时间线中的事件不得互换。本卡不检查或改写章节简写、正文。

## 0. 通用核验规则

- 每次从“发现危险”到“完成处置”必须分清：**独立测量／分析建议／合法下令／设备执行／现场验收／通知受影响者**，任何两环都不自动等同。
- 仪表、备用设备、通讯链路和合格人员必须提前伏笔；不能在高潮突然出现。维修、医疗、泄洪与电力切换的专业决定只能由其对应责任人作出，许砚仅负责物流、信息核对、联络、实际交接。
- 不用固定分钟数替代情节逻辑。下文以 **F0—F7 / I0—I7 / G0—G8** 表示相对阶段；正式章节简写之前另核操作窗口、路程、受害地点、故障范围。*顺序是约束，不等于各节点间已算出时长*。
- 人员伤亡需有可解释的独立现场链条；“本章死人”不能成为某一份错误报告直接致死的证明。事故责任、行政许可和赔偿也不得由许砚一人判决。

## 一、第一卷015—018：山区河谷洪水、联接销与漏户

**地形与依赖拓扑（文字示意）**

`上游暴雨汇流 → 老闸上游水位 → 受限分段泄放 → 下游低洼聚居点`；`下游排水泵 → 低洼住户积水排出`。老闸手动机构需要一枚与原规格匹配的**联接销**，而同一枚实物正在下游泵临时维修件上使用。取回销件会让排水泵暂时失去原修复能力，**先保障下游临时抽排，再由水工专业班组判断能否拆换**。临时住屋不在旧地址清单内，与电子通知链缺口叠加。

| 阶段 / 对应章 | 事实先后及必要依赖 | 有权人员与可见证据 | 必须发生的代价 / 不能跨越的边界 |
| --- | --- | --- | --- |
| F0 / 014 | 林禾证明销件被移到下游排水泵；位置、归属、取回风险通过实物核查 | 林禾提供历史线索，维修人员和泵站保管人核真件 | 不能因为“找到了”就立即拆，先解决下游排水问题 |
| F1 / 015 | 上游降雨和实时水尺形成预警；两处独立观测相互核对，给出**预警窗**而不是神奇精确的洪峰时刻 | 持证/受训水文人员出测量意见；许砚按临时与常住清单找运输 | 不以模型一份预测直接决定泄洪 |
| F2 / 015—016 | 水文与泵站人员评估抽排替代、备用电、吸排能力和接管班；居民被告知可能牺牲什么 | 泵站操作员与水工人员确认独立临时抽排能持续覆盖必要窗口；黎照保留异议 | 替代设备的**可用容量和切换耗时未定稿**，正式写前核 |
| F3 / 016 | 在F2可行的基础上，才形成限定幅度、限定条件、可撤回的专业处置方案；人员和资源分别到位 | 水文员定条件，合法应急负责人下达允许范围，持证操作员复核可执行性 | 黎照不能凭签字把未到位的机具变出来；拒绝撤离的人仍需记录 |
| F4 / 016—017 | 夏芒协助核物，合格工人拆换销件、核机械行程与隔离状态；下游临时抽排先实际启动并有值守 | 水工/机械班组现场检查，独立复测；许砚不直接开闸 | 旧闸本体可能卡滞，不得把“销件装上”写成机械全面修复 |
| F5 / 017 | 专业班组依实时测量尝试有限分段泄放；闸门卡滞及回水使低地受淹，救援任务临时改变 | 专业人员决定暂停/调整；现场记录真实水尺与闸门动作 | **不能通过万能模型自动预测和纠正卡滞**；危险由水情、实物老化和操作窗口共同构成 |
| F6 / 017 | 许砚发现一处**未入旧名单的临时住屋**没有被真人确认收到撤离通知；志愿者叶澄在该处等救母亲，母亲后经救援存活但受伤 | 许砚负责复核通知缺口，持证救援人员评估进入条件 | 漏户是许砚协调错误；**救援工人重伤另须有具体受困/回水的现场链条，不自动全部归因于叶母漏户** |
| F7 / 018 | 洪峰过后专业人员确认风险降低，实地清点幸存者与受灾财产；一位受伤救援工人最终不治 | 现场救援、医疗与调查人员分别出具结论；许砚公开通知单、缺口与自己责任 | 不用“救了大多数”抹掉死亡和赔偿，叶澄不能当场简单原谅他 |

**正文前未定/必须复核**：上下游相对方位与距离、老闸有效通流与可控开度、临时泵是否有可行吸排条件、回水淹没住户先后、撤离与车队单程时长、临时住屋为何没有被纳入地址表、伤者受困与治疗时间。不得填无来源的流量/水位/小时数。

**剧情特有胜负**：漏户造成角色关系裂痕，最终第六卷用真人双重名单复核与新人独立值守纠错，而不是重拍同一枚销件。

## 二、第二卷031—036：压力设备失控事故

**依赖拓扑**：`生产计划赶工 / 条件许可 → 老压力设备投入试运行`；`阀座磨损与卡滞 → 隔离/调节能力不足`；`取压支路/取样管局部堵塞 → 显示数据与真实压力响应不同步`；`观察员缺席、风险报告限制被删、停机异议未完成处理 → 错过及时停止窗口`。这些是**叠加风险**，任何一条单独存在不等于必然导致伤亡。

| 阶段 / 对应章 | 必须验证的现场因果 | 谁决策及留下什么记录 | 不得忽略的专业边界 |
| --- | --- | --- | --- |
| I0 / 022—028 | 设备有改装史与磨损征兆；工人提出停机、拆检和校验；模拟专家不能代现场确认 | 老工人原纸本、设备清单、校准员复测；夏芒组织记录 | 预警必须在事故前存在，不可事后凭回忆临时新增 |
| I1 / 029—030 | 部分合规原料入厂和合法小范围生产先成功，医院确有受益 | 专业生产、质量人员各自验收 | 物流交付成功**不构成**旧压力设备全范围安全证明 |
| I2 / 031 | 工人要求对阀座和仪表独立检查；时间紧、替代产能有限 | 设备负责人决定检修窗口与风险限制，停工异议有受理时间 | “看到裂痕”不直接等于掌握内部全部磨损程度 |
| I3 / 032 | 技术报告的“仅证明接口读取正确”被压缩为乐观的对外摘要；许砚发送更正但**未追到有权开机者确认旧版本已撤回** | 文档发布/审批/实际生产许可三条线均留版本号、签收、条件及时间；黎照参与的是附条件行政许可 | 行政许可≠质量许可≠设备专业安全许可；邱绍辖管的接收渠道收到警告≠邱绍本人必然已读 |
| I4 / 032—033 | 专业现场负责人在风险未全部排除条件下作出继续/限定试运行判断，主管工期压力形成实际影响 | 现场开机人、值守人、专业负责人有独立可追问的角色和签字 | 不能让模型“恶意直接操作阀门”；许可失误不能取代设备故障 |
| I5 / 033 | 真正过程压力变化与取样/引压支路受阻的仪表读数产生滞后差，阀座卡滞使隔离措施不如预期；工人先发现异常并依规尝试停止 | 现场原始仪表记录、独立痕迹、值班和操作日志核对 | 具体结构与失效顺序应让合格机械/工艺专家在正文前审定；不能凭堵塞一项推导压力瞬间无限增大 |
| I6 / 033—034 | 停机与抢险仍有伤亡，随后的安全隔离、救治、事故调查开展 | 专业应急人员和医疗人员分开工作，调查机构封存原件 | 需补受伤者所在位置、隔离失败位置、警报延后多长、可否及时撤离 |
| I7 / 035—036 | 维修申请、交接回执、更正版本和原始曲线表明警告曾进入审批接收环节；邱绍撤回“从未到达”的断言 | 黎照依法保全，主管部门按权限限制其单独发布风险简报，正式责任另查 | 警告到达≠邱绍主观明知；许砚纠正不足不能被公开反杀洗掉 |

**正文前未定/必须复核**：设备压力介质类别、阀门属调节/隔离何种功能、取样/引压管的实际安装位置、感测滞后的物理链、开机许可审批先后、安全联锁是否独立于受堵支路、人员所在位置和伤亡机理、停机可行窗口。**在没有这些参数前，只能说多因链合理，不可宣称工业工程已闭合。**

**剧情特有胜负**：主角的公开胜利是迫使错误说法撤回，真正痛处是他本人也没把更正追到执行终点；卷五099他必须改正这件事。

## 三、第五卷097—105：多城电网错误传播与局部隔离

**必须分开三条线**：
- **信息线**：B备用馈线的负荷测量有漂移，中心风险报告低估实际承压；能源与交通等机构分别沿用共同来源；现场工人独立读数的异议经身份/路由延迟，未送达所有有权调度席。
- **物理电力线**：A区域的受限主干在运行条件与设备缺陷叠加下保护动作；按已批准的自动转供方案把部分供电负担转给**B备用馈线**，但B实际可用余量小于中心报告估计，再发生过载保护动作。**保护装置按自身规则动作，不是模型隔空拉闸**。
- **被救的C分区**：C有提前确认的本地应急储能/独立供电及符合资质的分区控制人。在099经有权调度席核独立现场读数和预案后，**先阻止C继续承接错误共享调度的增量负荷、确认可按规转入局部备用供电**；C一处医院获得有限时间的安全供电。C不是A/B备用馈线的物理上游，不能再写成C被保护引发A/B崩溃。

`错误传感器(B) → 共享容量报告低估B已用负荷 → 多方计划对B转供`；`A保护动作 → 已授权转供请求进入B → B真实余量不足 → B保护动作 → 部分医院/水厂失电`；`C独立读数＋旧无线电 → 有权调度席决定隔离与备用 → C局部获保`。

| 阶段 / 对应章 | 发生了什么 | 真实权限、信息证据与因果边界 |
| --- | --- | --- |
| G0 / 090、093 | 独立计量预算被推迟；医院、水厂部分共用供电保障路径，备用容量不足同时保障全部关键负荷 | 预算决定必须记录；主干与备用拓扑在作者后台固定，不能只在灾时冒出 |
| G1 / 094—095 | 少量地区分阶段重联取得实际生活收益；值班工发现中心摘要和现场不符，旧无线电只覆盖部分站点 | 唐序只提供技术方案；是否合闸由各地有权调度决定 |
| G2 / 096—097 | B馈线测量漂移，中心共享底稿低估其实际已用容量；跨机构模型在各自权限内引用报告 | 读数差异应有不同来源、采样时间和复测人，不能以同一个仪表证明自己错 |
| G3 / 098 | 能源、交通两家“独立审核”实际复用G2底稿；A馈线承压征兆、C分区独立告警出现 | 报告共源不能直接证明所有设备一定跳闸；现场合格人员发起复核 |
| G4 / 099 | 许砚用恢复的低覆盖无线电追到**C的有权调度席**；对照现场实测，专业人员正式停止C错误接入并落实可回退局部备用方案 | **真实赢**：C医院在后续故障时有短时供电；隔离/备用决定由合格人员做，不是主角按开关 |
| G5 / 100 | **未被C局部隔离消除的A、B物理风险**继续存在；A主干因实际承压/设备状态达到保护动作条件，已有转供安排部分流入B，B真实余量不足又触发保护 | 必须确定A保护动作依据和B的实际余量；不得把“AI报告错”写成直接让电网爆炸 |
| G6 / 101—102 | 电力调度人员按实测选择切负荷与保护设备；医院/水厂各有实际备用时窗，无法同时保全全部用电，有地区停水、停电与抢险伤亡 | 医药、供水安全分别由持证人员判断；伤亡必须有实际现场链 |
| G7 / 103—104 | 黎照保留预算决定、原始仪表与告警路由证据；许砚组织实际安全饮水、人员转运，自治车队自身也有限 | 水质不合格不能靠AI建议就可喝；救援不等于重联 |
| G8 / 105—106 | 调查逐项区分错误数据、实际运行、告警延迟、备用缺失、人类预算选择与局部救援成效 | 不能让唐序负责全部故障，也不能以局部C成功粉饰B区与患者损失 |

**正文前未定/必须复核**：A/B/C具体电气单线图、各馈线负荷与可用余量、保护整定与动作次序、储能切换条件和持续范围、医院及水厂实际应急负荷、潮流重分配是否能造成B过载、谁有权调度和什么站点能收到告警、受伤者处境。数值须先由作者固定并核查，不允许用没有推导的“几分钟全城瘫痪”蒙混。

**剧情特有胜负**：099不是又一次“报告打假”，而是许砚必须在有限告警路径下**找到真人权力接口、承担C分区暂停负荷和有限备用的取舍**，与其他地区的失电形成对照。

## 三点五、用于防止作者“时间和容量开挂”的最低可检查条件

下面只规定**哪些约束必须比较**，不是提供设备操作程序，不表示已获得工程专业验证。所有量均先由作者单独设定、审查后再使用；**不能为满足情节先写结论，再倒填数字**。

| 事故 | 必须成立的内部约束 | 若不成立，剧情应如何处理 |
| --- | --- | --- |
| 卷一撤离 | 临时住户实际可用的撤离时间窗，与确认信息→安排车辆→往返转移所需时窗相比；至少某些住户能撤、漏户因通知滞后更危险 | 不得写全员毫无准备却全员及时脱险；需要将漏户发现时间、车次安排或被困人数按实际条件调整 |
| 卷一临时抽排 | 拆走联接销后，下游替代抽排实际可用能力应覆盖约定的临时范围和时长；上下游泄洪/回水风险不能互相忽略 | 临时抽排不足时，不得让合格人员无条件同意拆销和开闸；必须承认相应灾损或改变专业选择 |
| 卷二报警与伤亡 | 真实异常发生、仪表显示滞后、班组发现、发起停机、隔离响应和人员撤离的先后要有物理解释；至少一条预先声明的风险控制失败才形成严重后果 | 若独立联锁或备用通道足以拦下危险，事故不应凭空继续；需改变故障范围或缩小伤害 |
| 卷五A/B级联 | B实际已承受负荷与转供增加量之和确实超过其可承载范围，且A保护动作、转供执行、B保护动作应有连贯的运行状态 | 若容量足够，不能仅凭共享报告错误造成B跳闸；应修改负荷假设而不是给保护装置写“自动失灵” |
| 卷五C局部保电 | C可使用的独立备用资源能支撑被保留下来的**有限关键负荷和有限时窗**；提前隔离C不能假定同步拯救A/B主干 | 备用不足时只能写短暂或部分保护，不能写全天、全区供电恢复 |
| 三起事故的责任 | “发出提醒”“管理者收到”“专业人员读过”“有权者下令”“操作实际完成”是五件不同事，各自要有可追问的证人和记录 | 缺少某环就不能直接判定某个人主观明知或将事故所有后果归罪于同一人 |

**未定参数不视为错误，但视为尚未关闭的生产前检查项**。三个事故都应至少在作者后台具备：一张简单位置/设备关系图、一张按先后标明人员的时间表、一张无法无代价两全的资源表、一份伤害及责任的独立事实清单。若仍没有可信参数，就以限定操作范围和明确无法确定的风险写故事，不用夸张工程数值营造科学感。

## 四、写作前验收的统一追踪卡
