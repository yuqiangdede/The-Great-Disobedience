# V5四组高风险工程场面的待核验清单（F／I／G／R）

> 更新：2026-11-11。唯一剧情以[V5逐章执行卡](./番茄发布向-十二卷130章逐章执行卡-V5.md)为准。本文件记录的是**待专业核证的条件和风险**，不是“已通过工程论证”的参数单；旧版工程假设和不同章节顺序留在Git历史。

## 通用规则

- 先固定剧情硬事实、人物岗位及授权链，再核设备结构、到场时间、人员位置、传播途径和损失；核证失败就调整动作细节与损失边界，不能造数。
- 许砚只协调车、货、人、证据与回执；电力系统由合格调度和现场人员、水闸由水文与水工、压力试运由具资格工艺负责人、医疗由医护和药师决定。
- “传感器看到”“网关发出”“任务归档”“人亲自收到”“专业设备动作”是不同事件，不允许因果跳步。

## F｜河谷洪水：015—018

**已锁剧情：** L-17是原住户之外的临时住屋；015许砚因原住户签收与广播记录合并而本人误勾整院已告知。016发现异议后撤销过度汇总，却仅托临时人员补访，没有具名接班和真人签收；017叶母受伤，018救援工人伤重不治。2056旧闸合法有限动作是历史线，不是此次洪水自动开闸。

**待核：** 住屋与水尺、道路、闸口的位置；通知到发车的时窗、撤离车次、通信中断前后顺序、意外开度或卡滞导致回水的范围与速度、救援工人受伤的独立链路。只可写“专业人员重估水情、尽力组织撤离”，未经验证不能写成保证及时到达的分钟数。

## I｜工厂压力设备：029—038

**已锁剧情：** 032许砚已经尝试追到厂门具名执行岗，却在实际撤票确认未得到时因保合同压力退让，不能等同于015漏户的同类粗心。赵峻拒绝危险开阀岗，仍可能依法担任评估隔离区外侧的外围观察职责；吴屹作为具资格的工艺负责人签发限定试运，邱绍施压赶工。事故致赵峻死亡，许砚虽然追到厂门仍未取得有权执行者实际撤票确认。030送院药品来自既有已检合格库存，不是029新原料隔夜量产。

**候选物理风险：** 老阀座隔离不足、读数迟滞、旧检修连接短管不完全受主保护覆盖、局部喷流或回卷至误划安全区——均**未确认可行**。

**待核：** 设备拓扑、保护覆盖、介质种类与温压、人员安全距离、侧廊暴露路径、撤离时间、热伤与救治链。不得让拒签危险岗位的赵峻无故站在喷口下，也不能在独立保护正常动作时凭空令主容器爆炸。

## G｜电网级联：083—106

**已锁剧情：** 智能医疗和复位让真实病人获益。十份报告并不真正独立；孟岚推迟第二套交叉计量购置并承担后果。陆惟已经限制B区**新增**负荷，但旧备自投/旧转供仍未由合格人员及时撤除；A区被保护切除后按旧逻辑转供，压过B的真实余量，A/B保护依条件正常动作仍造成级联。C区局部保住医院转院窗口，付出生产停机成本，不抵消B区灾损。

**V5继续核查**：092—097陆惟已实行限新增和部分减载；必须列出旧转供不能安全撤除的现场条件、医院保供候选、已实施与未实施方案，不得以‘维修车堵车’取代全部技术原因。

**待核：** A/B/C真实拓扑，负荷和保护整定，备用能力、延时、联动逻辑、旧转供仍能执行的合法状态、警告到调度的耗时以及病人救援范围。不允许把“B已限新增负荷”直接改写成“B已解除旧转供”，或让许砚直接拉电闸。

**待核：** 地点与上下游传播、道路转移时间、车辆数、人手、洪峰窗口、闸站操作边界、失联及恢复通信的先后。此处不能重演F的同一机械故障，也不能靠不可能的车程或万能水闸保证全员平安。

## 发布前核证记录要求

| 栏目 | 必填内容 |
|---|---|
| 事实与权限 | 专业岗位、合法授权、角色能做和不能做什么 |
| 地理与设备 | 拓扑、位置、出入口、受影响区域，来源或现场依据 |
| 时序 | 数据采集→通知→决策→执行→传播→救援，含每一步不确定性 |
| 反证 | 若保护正常、车迟到、人员不在场、设备未覆盖，情节是否仍成立 |
| 结果 | 真正救到谁、伤了谁、赔什么、证据谁保存 |
| 核验状态 | 专家及数据来源；未完成则标“待核”，绝不写“已验算” |

截至本次修订，F/I/G/R仍为**待专业核证**，本文不宣称通过物理验证。
