# 配送切入点改版：人物职责、六卷章纲与130章简写同步复审

状态：2026-10-31设定层、章纲层与章节简写层的修订记录；并非正文验收。依据《许砚职业履历与叙事能力边界》，保持原六卷130章、第一卷18章及原有重大事件和结局。不修改正文。

## 一、修订目的

原开篇以配电站冷却泵、十二年后修取水泵切入。现改为2049年城西即时配送站的医院急件受阻、2061年社区交换站药品领取纠纷。主角许砚的基础能力是**旧网接口工程 + 配送及资源协调 + 日志与交接证据**，不是全能电气、水务或压力设备工程师。

这一职业既能让大众在第一章理解“有药、有车、模型会计算，却发不出合法跨机构执行任务”，又能在第三卷实际发挥调查司机路线和模型反馈链的优势。

## 三、必须坚持的证据边界

1. 模型显示“已派单”“执行成功”只说明相应系统记录，并不直接证明药物送到、病人用上或闸门真的移动。
2. 医院药师决定批次是否可用，水文员决定现场测量是否可采信，设备负责人判断机械安全，黎照签程序行政责任；许砚负责实际交接、接口边界和自己已做的决定。
3. 第017—018章许砚确有漏通知问题，但救援工人的伤亡与该失误的因果程度尚需调查，不写成既定法律判决。
4. 第032—035章许砚确有未纠正错误摘要的责任，但不能把其误写为压力设备安全签字人；设备事故的具体工程原因、审批责任、赶工和观察员缺席须分别留证。
5. 2049/2056/2061三个时间点不互相串线；第一卷第014章以前不得让弦-9提前说出2056年真实现场操作者。
6. 130章概要与单章简写的修订以独立单章为准同步；既有正文未编辑、未验收，不得宣称正文已重写。

## 四、后续写正文的执行提醒

读者需要看到角色把事情做成或做错，而非听完整制度讲座。许砚可以亲自送急件、核对运单、找司机、追一张不见的回执、公开一条被掩盖的版本差异；夏芒做危险设备的测量和试验；黎照保全反对意见和审批证据；医生、药师、水文员、居民自己说出专业与生活代价。每次涉及高风险设备，明确谁有资格、权限、独立信息、实际回退能力和承担损失的角色。
