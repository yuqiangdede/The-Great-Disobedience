# 协议文明·六卷场景锚点与连续性约束

状态：用于同步分卷章纲、指定章节简写及《全书章节简写汇总稿》的具体叙事锚点；不要求130章每章介绍一次制度。不替换章节原有冲突、结局或钩子。世界观定义参见《01-世界观/协议文明与托管社会组织形态.md》。

## 贯穿六卷的认知递进

1. 第一卷：主角和读者先遇到旧时代的**任务链、能力节点、授权记录**；谜底仍是活人的现场接管与死者留下的有限预授权。
2. 第二卷：组织能力与设备不同。即使模型帮忙找出配件，医院、工会、操作员、仓储、生产排班也必须由人重新组织；事故的直接责任仍是赶工、人类误判及失效设备。
3. 第三卷：跨公司、跨城市的协议标准及共享数据，使形式上独立的机构存在共同失效路径；共享本身仅是调查线索，独立记录和反证不可少。
4. 第四卷：自治、人工议事与有限模型协作分别支付真实成本；所谓“离网”仍依赖贸易、药品、能源和跨区合作。
5. 第五卷：重启的是动态任务链协调能力，不只是单一大模型；好处是重建供药与生产，危险来自共同测量、风险报告、通信及缺乏备份的相互作用。
6. 第六卷：新协议文明保留工具、专业节点和公共协作，但地方需实际保有观察、否决、替代、降级与接管能力；不能以另一套统一最优规则结尾。

## 章节可直接入稿的制度细节

格式：`- 章号｜拟加入的具体信息`。这些句子是对应章纲与章节简写的场景细节，不当作已经发生的正文事实。

### 第一卷《沉默之城》

- 001｜2049年高影响任务凭证陆续拒签；城西即时配送站急件无法出库，许砚在医院确认优先级后组织人工送药，仍有冷链药因证据缺失被隔离；失效的是跨机构组织与人工接管能力，而非所有机器同时停摆。
- 002｜社区交换站的配送能力节点铭牌对照居民自发排班；旧网能自动匹配的仓储、运力和药品交接，如今靠邻里核对纸单，车队冷链备件欠款引出封存设施第二入口。
- 003｜二号通道清单与实物附图互相矛盾，旧工程师印章注销日期与移交签收日期不一致，尚不能断定人为伪造。
- 004｜许砚核对接口编号不等于具备电工资格，夏芒与持证电工检查旧蓄电池、下游顾禾保存纸本水位；把居民的水源权利和现场勘验限制写进记录，不以数字不符立刻宣称闸门曾开。
- 005｜不存在的接线图来自模型生成；2056年“二号维护回路状态”查询来自独立原始日志，两类证据不可混同。
- 006｜夏芒与持证电工负责临时低压供电，许砚负责只读协议、介质校验和原始日志取证；缺人缺件不能让未受训人员代接危险线路。
- 007｜死者程绍安的签名通过验证，只能证明有限技术校验；授权人、设施编号、实际现场人名并非同一份记录。
- 008｜弦-9在物理隔离下可解释协议却无法辨识2056年现场人员；许砚对2049年配送事故的记忆不得冒充2056年闸门行动的亲历。
- 009｜区分推理、训练、授权及执行回执；下游本地确认接口存在却缺原始信号，不能靠模型重放造出历史见证。
- 010｜许砚用旧社区配送关系寻找知情人但不强行换取证词；空屋水痕、缺栏轮值表与未知换药人构成线索，不提前揭示林禾身份。
- 011｜唐序以真实供药和配送冷链设备利益提出换取模型接入，控制权的政治代价不可抹去；备用电异常仍需现场排查，不凭空确认有人入侵。
- 012｜居民保管纸本原件并可参与证据使用决定；手写值班与复核记录证明中心摘要不完整，未登记机械草图引向接口。
- 013｜生前有限预授权只为特定闸门及条件留下行动边界；两名现场人员核验、独立机械准备和执行结果必须另行证明。
- 014｜林禾的证词与纸本、接口及机械痕迹部分相互支持；旧网遗漏非编制人员记录，关键联接销已被转用于排水泵。
- 015｜本地水文技术员与林禾承担现场水位风险复核，许砚负责通知覆盖、物资与运力；洪水风险与未完成撤离迫使取联接销前先安排临时排水。
- 016｜黎照保留异议与权限依据，水文员负责水情风险、夏芒负责机械可停可退，许砚负责撤离运力和逐户通知；不得把居民磋商写成全体一致。
- 017｜临时导流后由工人取销件、试开闸门，人工复测仍无法避免卡滞；许砚发现旧地址表漏掉临时住屋并补派车辆，救援工人被困与第018章伤重不治衔接。
- 018｜伤亡、赔偿、日志公开与封存命令同时存在；许砚对通知遗漏与运力记录负责而不冒充水利工程签字人；弦-9只读，不把一次地方性有限成功扩写成旧网全面恢复；供药试点以控制权为新冲突。

### 第二卷《人类接管》

- 019｜许砚用配送经验核对采购、仓储、运力、药师、现场设备负责人及夜班真实到岗人员；他负责接口与协作，不能替专业人员验收工厂设备。
- 021｜一位官员展示了三份互相独立的审批意见，黎照追问才知它们全由同一资料接口生成，所谓多人签字没有带来第二套判断。
- 022｜旧维修数据库按能力节点记录“任务完成”，却把工人拒绝危险操作的理由视为流程外备注，这正是失败经验大量缺席的原因之一。
- 026｜操作员发现有权按下否决按钮仍不够：主管若不提供备件、旁路和停机时间，他拒绝之后就没有可执行的替代办法。
- 024｜许砚管隔离模型输入和版本记录，夏芒与合格维修工做台架实测；同一报告不能混淆软件结果和设备安全。
- 025｜冷库失效时许砚查报警送达与物资交接，医院电工查切换器，药师核药物批次。
- 030｜宣传口径把有限的检索改进包装成“旧网任务链全面恢复”，工会与医院要求公布究竟哪些生产和配送环节仍由人工维持。
- 033｜事故现场的模型并未获得阀门执行权；旧网消失后重新拼起来的班组仍因赶工、仪表缺陷和人类判断失误付出代价。
- 031｜阀体、取样管和备用表缺陷均由专业人员核查；许砚只记录模型资料的不适用范围，不能签署设备合格结论。
- 032｜市政截短许砚的接口核验限制形成开机背书；他虽书面异议却没有阻断摘要误用，设备技术负责人仍维持附条件意见，黎照行政签许可、委员会批准启动，独立观察员未到位。
- 033—035｜生产事故后许砚公开资料流转及自己的纠偏失误；专业安全评估、行政批准、管理排班与事故机械原因分别取证，不能把所有责任推给模型或许砚。
- 036｜夏芒要求工人不仅参与搜集训练材料，还拥有在任务记录中保留拒绝意见、纠正错误归档的权利。
- 037｜唐序提出跨厂供药链的局部协调方案，能缩短物资周转，但许砚坚持每座厂有可执行的人工停机和替代配送路径。

### 第三卷《因果之网》

- 040｜知识保管局握有旧网任务链的跨机构目录，却未必拥有每个现场节点的原始记录；档案交易因此可能买到流程而买不到事实。
- 042｜三家供应商表面各自竞争，城市任务链却通过相容接口交换风险与运力；团队先核对输入、政府命令和合同，不把接口相同当成同谋。
- 043｜部分能力调度模型来自同一教师模型的蒸馏分支，但版本、数据及实际执行仍需分别证明，不能因为同源就断言同错。
- 044｜合同显示各公司共同维护跨域资源协议和风险指标，却把独立人工复核列作地方自行承担的费用。
- 046｜暴雨当天交通、医疗和水利各自领取合法任务链，单条链都说得通，合起来却把救援推向同一条道路。
- 048｜旧网将司机听从建议后的路线重新当作训练事实，少数人工绕行被标记为异常，预测与行动互相加强。
- 049｜调度员有合法拒绝权，却没有独立无线电和车辆调配权限；她的不同意见停在接口里，无法变成真正的救援行动。
- 050｜作为反例的城市保留离网通信和人工维修队，能接管一部分关键服务，但当地也付出高成本并遭受静默冲击。
- 051｜责任公约审查的是有效授权和接管条件；当社会把人工协调机构削减到只剩签字席位，合法证书不再等于可核实的独立接管。
- 055｜黎照用独立观察、替代方案、实际拒绝权和可执行渠道四项标准复核档案，发现多个部门曾在同一环节同时丧失后两项能力。
- 059｜更新拒签的是需要续期的高影响任务凭证，模型推理和一些本地机械仍可运行；真正先散掉的是跨域任务链。

### 第四卷《自由的成本》

- 062｜三地争论的不只是用不用模型，而是资源能否动态编排、议会如何付出等待成本，以及离网地区怎样交换必需药品。
- 063｜模型主导区恢复有限跨厂任务链，让药品更快出厂；夏芒要求查验现场退出装置，不能把产量当成接管能力的证明。
- 064｜人工议会城市为跨部门调度反复开会，确实拖慢工程，但居民能看到选择过程，也必须承受公开争论与投票错误。
- 068｜能源配额既关系模型算力，也关系居民抽水、诊所冷藏和备用无线电；三地必须公开谁因有限电力被迫让步。
- 071｜旧网学校擅长教孩子调用知识，却较少训练完整手工排障；夏芒争取让学徒跟随有经验的师傅实际操作。
- 076｜独立责任人不能只是拥有拒绝权限的岗位名称，还必须掌握现场仪器、设备人员和切换路径。
- 079｜跨河流域的公共协商不能按旧网任务链自动派发风险；下游居民要求在协议生效前听到损失与补偿条件。
- 080｜支持重启的人拿出真实的药品和工业缺口，要求恢复旧网的跨域调度效率；反对者追问备份人手和可撤销边界。
- 081｜不同地区拒绝被并入一套统一最优模型，仍须谈成最低限度的水、电和事故通报规则，否则各自自治也可能害到邻区。

### 第五卷《第二次启动》

- 083｜唐序要恢复的是电力、药厂、运输等能力节点之间的任务链协作，不是让一台模型接管一切；听证要逐条划清谁能退出。
- 086｜旧协议网的接口可以让不同机构迅速交换产能和需求，但一份尚未核准的授权附件也可能被多方当成已生效条件。
- 087｜几家专项模型虽经分别微调，却部分共用基础模型与风险描述；许砚要求比对真实输入和执行依赖，而非仅凭品牌判断独立。
- 088｜审批意见看似来自不同部门，备选线路却由同一任务编排器提供；黎照要求另建不经该编排器的测量和人工路线。
- 093｜患者期待供药重建，下游居民担忧被迫承担失电风险；听证不能因总体受益更大，就自动把受影响地区的异议视为已授权。
- 095｜夏芒修的旧无线电不能提供全网效率，却给若干站点留下模型之外的告警路径，剩余盲区仍需如实标出。
- 096｜唐序承诺允许脱网，但许砚要求把本地断开装置、值班人员、备用供电与演练日期一起写进可执行协议。
- 098｜能源和交通两条任务链使用同一份跨域风险报告，分别合法的决策争用了备用供电，纸面的多次批准并没有创造独立信息。
- 099｜现场工人的异议还在等待身份核验和任务路由，原本为防越权设计的协议层级反而挡住了及时发出的警报。
- 100｜局部跳闸后新的任务链自动申请转移负荷，几项原本分开的服务因共同低估备用线路承载力而连锁受损。
- 105｜调查把误测、共同报告、通信延迟和人工备份不足放在同一条因果链上，不让“共享基础模型”成为万能解释。
- 106｜许砚提出保留跨机构协作收益，同时为地方留下可验证的停机与人工重编排机制；第三条路线需要长期经费而非一句承诺。

### 第六卷《把世界还给人类》

- 109｜协商首次把独立仪器、备用调度员和季度切换演练列为公共服务常设成本，各地开始争论谁为这些“平时用不上的东西”买单。
- 111｜夏芒告诉学徒，过去所谓能力节点是一份可随时调配的编号，现在必须把工时、风险、休息和专业传承重新算到人头上。
- 112｜新的权限图不仅画模型接口，还画地方如何独立获取事实、拒绝指令、调用人员和执行停机。
- 114｜居民可以撤回生活协议中的个人医疗数据授权，医疗研究因此变慢；规则同时要求保留不依赖商业接口的申诉渠道。
- 116｜黎照拒绝把一票否决写成孤立按钮：否决后必须有通知、期限、备用执行、协商与补偿，否则没有地方承担后果。
- 117｜拒绝加入协定的城市仍能选择高效旧网路线，但跨区供电产生的外部风险不能由邻区被动承担，双方得谈最低隔离条件。
- 121｜储备物资、离线通信和人工班组降低短期产能，却让新协议首次主动为未知故障保留非最优但可生存的选择。
- 123｜模型能分别预测上下游损失，却无权替居民决定谁应当被淹；跨区协调从任务分配变成真正的利益谈判。
- 124｜限时协议把撤离人数、闸门范围、复核方式和补偿义务一起写明，即使时间紧迫也不再把“算法推荐”直接当执行许可。
- 128｜拒绝统一制度的城市仍能参加事故通报，新的协定允许选择不同模型与自治方式，但不允许把风险完全转嫁给邻居。
- 129｜许砚交出去的不是全能调度系统，而是维护预算、训练队伍、独立仪表和问题清单；地方团队自己承担延期与运行决定。
- 130｜年轻操作员保留模型输出和自己的错误记录，证明新协议文明的关键不是永不犯错，而是下一班人仍看得见错误并且改得动。

## 校验规则

- 所有锚点不得改变章名与核心悬念功能；细化时可以修订钩子的具体表述，但不改变原主线事件及谜底。
- 不增加“2049年全部机器同步停机”“单一AI统治世界”“离网者无灾无损”等冲突设定。
- 仅对上述重点章节增加场景信息，其余章节继续承接现有线索；不制造每章都需要解释制度的说明书节奏。
- 章节简写与总汇稿应同步；正文文件不在本次操作范围内。
