# 第七部分：进一步深化——最终科学谜团

我建议在六卷主要故事之外，留下一条尚未完全解释的研究线索，让整个世界观更加深邃。

## 十二、因果闭合定律，可能还只是表层

人类最初认为，因果闭合只是大规模预测系统导致的社会与控制问题。

但在最后一卷的研究中，科学家发现了一些无法完全解释的现象。

不同地区、使用不同设备、甚至并不直接共享数据的高阶模型，有时会产生高度相似的长期预测偏差。

这些偏差并非普通的数据污染就能充分解释。

但现有证据也不足以证明未来能够影响过去。

科学家提出三种互相竞争的猜想：

| 假说     | 内容                             | 意味着什么             |
| ------ | ------------------------------ | ----------------- |
| 共同因果结构 | 不同模型都发现了现实世界中相同的深层规律           | 因果闭合是可以通过数学进一步理解的 |
| 隐藏信息通道 | 人类还没有发现某种普遍存在的信息关联机制           | 模型可能利用了人类无法观察的信息  |
| 反事实反作用 | 高度精确且广泛实施的预测，可能存在超出现有反馈理论的物理效应 | 因果规律本身可能需要被重新认识   |

第三种猜想最有科幻潜力。

但不建议在主线中直接将其确认为时间旅行或超自然能力。

它可以成为世界观深处的一道裂缝。

人类已经重新获得了一部分控制权。

却发现自己对宇宙的认识，也许远没有想象中完整。

如果未来真的会以某种方式影响现在，那么“自由选择”又究竟意味着什么？

这能为续作留下非常大的空间。
