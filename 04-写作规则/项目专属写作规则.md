# 《大模型不听话》项目规则

## 作者确定的创作与审查优先级

1. **首要：情节吸引人，每章都有钩子。** 卷纲、章纲、简写和正文都要关注人物目标、冲突、选择及后果是否让读者愿意继续读；每章设计并检查与本章情节、人物处境相连的有效钩子，能激发对后续发展的期待。钩子可以是悬念、风险、发现、人物关系或即将到来的选择，不必每章都靠突发危机或强行断章。审查时先说明本章的吸引力和钩子是否成立及原因，不能用总分或语言合格掩盖其不足。
2. **第二：正文不能有明显 AI 味。** 写作时保持自然中文和人物各自声口，审查时结合上下文识别并修复有实际阅读损害的 AI 味；不得为了消除形式特征而削弱情节吸引力、钩子、人物个性或情绪张力。
3. **其他写作、审查及工程指标次之。** 它们服务于作品质量；需要取舍时按上述顺序判断。既有事实、设定一致性及必要的审批和交付要求仍须遵守，评分不能替代对首要目标的具体判断。

### 2. 危机事件与专业分工双轨制（设备/水泵危机合理化写法）
- **工程事故合理且必须保留**：水泵卡滞/损坏、联接销被借调、压力容器局部超压、电网跳闸、老闸卡死等危机必须存在，用于制造倒计时、物资挤兑与灾难紧迫感。不得为了避开工程戏而削弱危机。
- **严格贯彻“双轨并行”叙事分工**：
  1. **专业技术操作轨（归持证配角）**：由持证水工、机械班组、电气工程师、工艺负责人、水文员、医生/药师负责。设备能不能拆、怎样装、受力如何、是否开闸、何时停机，由他们做专业判断并承担专业责任。

六卷分配六种不同的主导阅读体验：卷一“未来旧城＋废墟寻宝”，卷二“超级工厂＋底层逆袭”，卷三“旧城冒险＋物证打假”，卷四“三城挑战＋生活奇观”，卷五“文明复位狂欢＋连锁救援”，卷六“专业团队接力＋新人独立纠错”。不能把每卷写成同一种查日志、讨论授权、处理事故的循环；卷内允许调查，但必须有具体争夺对象和会发生变化的现实处境。

**每卷至少三次明确兑现：**①现实中确有好处的“世界真厉害”场面；②由这些便利或组织方式本身引出的成本、盲区或利益冲突；③真实的翻盘动作，改变至少一项救援、交货、暂停、保全、费用或权力结果。章纲和简写优先用“人、车、货、设备、收货人、见证人、时间限制”表达，不把设定解释当戏剧。每卷设置不同的外部压力：洪峰、医院断药倒计时、档案保全时间、三城公开挑战、复位风险及跨城协作成本，形成差异化追读。

四卷所谓灾难演练必须事先限范围、限风险、设可执行回退且不侵害不知情人的安全，之后真实水电事故仍独立发生；五卷先充分写重启真实成功，不能预设“重启派都是坏人”；六卷终极胜利必须由有资质的当地操作员和授权团队完成，许砚承担协调，不越权代替专业人员。沿用原主纲全部生命代价、2056年闸门真相、2049年静默机制和130章编号，不能为爽点删除因果。

## 进一步降低阅读门槛：人物只吵眼前的事（新增强制约束）

**总原则：人物处理生活中的麻烦，不替作者讨论“因果闭合、治理范式、授权体系”。** 对读者来说，先发生“拿不到药、车开不走、工人不准启动、救援车被调走”，再有必要了解技术和制度。设定在作者心里完整，呈现给读者时是行动、表情、物件、利益与后果。不得把全书写成审批纪要，也不得为降低门槛把AI社会的独特性删成普通灾难救援。

### 可直接执行的戏剧化替换

| 抽象台词或说明 | 更优先出现的角色行动与台词 |
| --- | --- |
| “几个模型可能存在共同的上游数据依赖” | 三份“独立结论”连错字都一样。许砚把纸摊开：“你们这是三个人看过，还是三个人抄过？”随后继续找原始来源，不能凭错字直接定论。 |
| “当前任务缺乏完整执行授权” | 仓库门开得了，车能跑，药就在眼前，仓管却说“你给我找个能收的人，我马上搬”。 |
| “系统没有记录现场异议” | 工人把旧维修本拍上桌：“昨天我说过不能开！谁把我的话删了？” |
| “预测反馈导致路径选择收敛” | “大家听导航，导航又看大家去哪儿，最后把所有车都领进同一条死胡同。” |
| “独立观测机制丧失” | “你们看了五块屏幕，河边有谁亲自去过？” |
| “制度之间有成本与效率权衡” | “你们那边有药，机器却停不下来；我们这边会停机器，病人却等不起。” |
| “人工接管需要具备能力条件” | “钥匙给你，你会开吗？开坏了，谁来修？” |

这些是**示范表达方式，不是规定必须照抄的正文台词**；人物应说符合自身处境、知识和性格的话，避免全员成为语录机器。说明性对话原则上先说“我现在要什么”，再说“你为什么不给”，最后落到“那怎么做”；必须解释的技术通常用一到三句人话交代，涉及专业安全时可以准确补充，但要放在人物动作中。

### 六个落地检查点

1. **一句话可复述**：每章能概括成“谁为了什么，跟谁抢什么，结果怎么了”，不是“本章讨论了授权合法性”。001—010尤严：十章各有清楚的现实事件或稀奇发现，禁止连续几章只查文件、读屏幕、开会。
2. **争的东西看得见**：一箱药、一辆车、一份工钱、一张工资单、一个住户名额、一次停机机会，至少让本场戏的争执落在某件东西或某个人身上。哲学命题留给读者自己体会。
3. **会议要改变现实**：听证、审批、谈判可以保留，但不要连续铺三场只有立场宣读的会议；必须出现现场受害者、具体报价/风险、实际让步、救援行动或可执行决定。第四卷三城优先争运力、供电、医疗，而不是轮流宣读制度优越性。
4. **先拍动作，再补技术**：优先让读者看到报告与货不符、警报与实测冲突、车明明存在却无法派出。不能以连续术语解释替代冲突、惊险和人物选择。
5. **胜利可核验、有代价**：许砚要靠自身擅长的协调、核物、追人、交接推动有资质者一起行动。真送到、真停住、真让对方改口才算阶段成果；读者不懂技术也能认清谁赢。伤亡、产权、合同、专业许可和后续赔偿不能为打脸被抹掉。
6. **科幻差异不可丢**：重要戏份尽量同时满足“普通人能看懂的麻烦＋角色有输赢的动作＋模型广泛代理社会决策后才会出现的特殊原因”。重启有真实便利，人类判断也会出错；不要宣称AI预知个人命运或自动拥有现实执行权。

**改稿验收：**如果删掉专有名词，读者依然能懂冲突，说明叙事门槛合格；如果再删掉AI社会背景，这件事就与普通现代救灾没有区别，则还需补入一处真实的托管社会特征。此项纳入现有剧情七维与阅读体验检查，不新设第38项AI味评分，也不为凑次数强迫改稿。


## 必须兑现的“小白爽点”与读者可见胜利（规划、简写、正文、剧情审查均适用）

**核心要求：主角要不断赢，而且让读者亲眼看懂赢在哪里。** 许砚的本事是找人、找货、核原始单据、恢复跨机构交接、争取合规的暂停和核实，不是比每个专家懂得都多。技术调查只作为胜利手段；一场戏如果只剩“发现接口异常、比对日志、写报告”，还没有改变任何人的处境，就不算完整爽点。可以让他输，但不能让他连续几章只旁观、辩论、认错或收集术语。

### 四种可轮换的胜利模式

1. **A：高深结论输给简单事实。** 专家、负责人或系统报告看似一致，许砚只问“东西在哪？谁签收？谁亲眼见过？”，随后找到药箱、空仓、车辙或真正收货人，在现场用物证推翻错误自信。允许专家在自己领域仍然正确；报告的错误必须有可追溯的来源。
2. **B：看不起他的对手不得不求他。** 对手嘲笑他只会跑车、送货，结果设备修好了，原料、运力或签收仍卡住；许砚用专业内的交接能力解决问题，出现“车真进厂/药真送到/管理者亲自来求”的直观回报。**不让他代替工程师、医生、水文员做专业决定。**
3. **C：规则压人，原始事实当众反杀。** 对手公开否认危险警告或截断报告，主角把原件、运输回执、当事人笔录、接收签字和现场数据彼此核对，让原来不能发声的人得到公开可信的说法。先写对手一句可辨认的否认和受害者的愤怒，再写主角找证据、当场展示、对手失去遮掩的结果。**签收不必然代表阅读、公开不代替判决，反杀不能洗掉许砚自身失误。**
4. **D：犯错有代价，之后的动作真变了。** 卷一漏临时住户、卷二对误用报告只发更正不追到底，分别造成真实代价；卷五他亲自追到报告接收人、现场负责人和有权暂停的人都确认，拦下局部错误；卷六即使他不在，制度也能凭实物交接与备用班组发挥作用。不得六卷都“发现问题—道歉—再犯同样的错”。

### 情节硬约束与验收问法

- **三章一次可见阶段性赢面：**连续三章内至少出现一次许砚或其直接推动的团队真救到人、真运到货、争回有限权限、追回关键证据、拦住一次危险动作或用实物揭穿一件谎言。不能用“查出了一个异常”“又开了一场会”“大家意识到很重要”充当胜利。高潮级胜利不必每章出现，必要的失败、铺垫、伤亡与喘息章仍要保留。
- **每卷至少一场公开或现场可见的翻盘：**让一个具体对手的判断、筹码或行动当场受到影响，读者能明确指出“谁先看不起主角、主角做了什么、谁因此改变、代价是什么”；不能只有作者旁白说许砚很重要。每卷还须有不可粉饰的失败或代价。
- **场景自检五问：**（1）许砚眼下争的具体东西是什么？（2）哪个人因为什么利益阻拦？（3）读者不懂软件也能看懂什么物证或动作？（4）这场胜利使谁获得/失去什么？（5）胜利为何引出下一场麻烦？缺少后两项就要补结果，而不是补技术解释。
- **具体对手必须有饭碗和底线：**第二卷邱绍为重建绩效删去风险限制并推诿，第三卷罗竞为旧档案的保管费与交易权截胡证据；他们有资源、有能力、有现实利益，也能在局部获胜。邱绍不能被写成凭一己之力操控事故的幕后黑手，罗竞不能被写成控制全球静默的超级反派。唐序保留救人的真实技术成就与可争辩的立场，不恶化为纯坏人。
- **反作弊：**不允许为了打脸把专家写成傻子、让对手主动交出证据、给主角万能钥匙、把程序上的签字当作已证实的现实行动、为爽点偷偷抹去死者和受害者的代价。胜利必须有主角主动动作、可信物证、独立专业职责与可见后果。

**分级检查：**全书主纲标注六卷各自的赢、输及四种模式分布；分卷章纲与简写标注“目标→对手→物证/动作→可见结果→后续代价”；正文审读时核查读者能否在不懂大模型技术的情况下感受到胜负。仅将上述内容纳入既有剧情/人物/节奏/悬念审查，不增设正文 AI 味第38项，不重复算分。
